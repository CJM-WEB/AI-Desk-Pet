## 实际实现与 TDD

- 复用 Node 异步 zlib，对 PNG 原始过滤流重新压缩并合并连续 IDAT；memLevel 8/9 取更小结果。全部其他允许块原字节保留，未知、动画、交错、不适用、损坏或无收益时保留原 Buffer。
- 工作预算为一张图展开 128 MiB、8192 个块；超过只跳过优化。PNG 优化器最初三个容量断言 RED，再 GREEN；独立复核发现空 IDAT 解析放大后，10000 空块用例先 RED，再增加创建对象前的预算检查，最终六项通过。
- 普通导出逐张读取可信句柄、核对实际 SHA、压缩并流入现有可信 ZIP 临时文件；源 catalog 和 manifest 只更新导出副本的长度/摘要及对应几何修订。草稿和已发布配置分别保存，不进行重新编译替换。
- 两项集成需求先 RED：图片体积不变、归档失败后仍准备后续资源；实施后两项 GREEN，覆盖真实回导、完整文档、本地文件不变及失败清理。
- 现有 E2E 素材集成测试原要求 PNG 文件编码字节完全不变，按获批无损编码契约调整为独立 inflate 后的完整过滤流与所有非 IDAT 块相同，且文件不增大。不以生产压缩器计算期望，也未退化为仅能打开。
- 独立规格/质量复核及空块预算定向复审完成，没有剩余 P1/P2 阻塞项。

## 默认角色包真实结果

探针与原始报告位于本机忽略目录 `.superpowers/sdd/2026-09-14-character-package-compression/`，分别为 `probe.ts`、`run-WTJq56/report.json`；实际样包为 `run-WTJq56/default-optimized.zip`。使用源码中的正式 `CharacterPackageService`、`CharacterStore`、`CharacterAssetService`；只复制仓库默认角色的 21 文件到自有隔离目录，不使用真实用户配置或对话。

| 指标 | 实测 |
| --- | ---: |
| 未优化参考 ZIP | 126,659,465 bytes |
| 正式服务优化 ZIP | 104,793,984 bytes（99.939331 MiB） |
| 减少 | 21,865,481 bytes，17.2632% |

| PNG 最大块数 | 2102，全部低于最终 8192 预算 |

参考 ZIP 采用相同原始 PNG、正式服务读取的文档及原有格式化 JSON，外层 yazl level 6，流式计数；它不是重新启动旧版本应用获得的时间基准。优化 ZIP 则确实由当前正式导出服务生成，之后由正式导入服务安装到新目录。完整草稿相等；发布清单只允许导入角色 ID、资源字节数/SHA、几何资源修订变化，其余全部字段深比较一致。仓库原 21 文件与导出源副本 21 文件 SHA 均未变化。

导出耗时 125.275 秒、导入 8.854 秒，发生在并发构建/测试期间，不是专用性能基准。无损重压增加导出等待时间，不作为桌宠平时的后台任务；本次没有测量导出后的长期工作集，也不承诺任意机器相同时长。

首次导入根目录尚不存在时，既有恢复扫描记录一次 `CHARACTER_IMPORT_RECOVERY_SCAN_FAILED`，随后导入成功；报告保留诊断及来源，没有隐藏为无错误输出。当前样包仅比上限小约 62 KiB，更丰富角色或其他编码源图仍可能超限；未实施网站上限调整，未真实上传。
