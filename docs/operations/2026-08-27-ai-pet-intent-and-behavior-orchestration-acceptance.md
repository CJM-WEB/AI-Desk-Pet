## 2. 已实现并纳入自动化的契约

1. 普通聊天只以合法可见正文作为成功前置条件。`activity`、`status`、`movementControl`、`behaviorPlan` 和 `capabilityPlan` 分别校验；单个隐藏字段缺失、截断或非法时只局部降级，不再杀死有效正文。
2. 文件和 PowerShell 能力以模型的真实 `tool_call` 表达操作意图。文件任务公告完整受控文件工具集；普通聊天不能被模型升级为 PowerShell；参数、授权根、逐次确认、冲突与真实执行结果仍由 Main 裁决。
3. Provider 只接收有界的人设摘要及“状态 → 多动作”的公开层级目录。公开数据包含名称、语义、描述和标签，不包含选择权重、私有状态或动作 ID、资源路径、帧和脚本；权重选择继续由 Main 使用私有清单完成。
4. 行为计划收敛为 `play_state`。明确动作先在指定状态内做语义匹配，最低阈值为 `0.6`；只指定状态时复用权重、冷却和重复抑制随机选取。动作完成后可在同一状态生命周期继续选择，状态切换、停止、拖拽、角色替换、重置和会话失效会取消旧生命周期。
5. 持久运动模式只有一个数值来源：`0` 持续静止、`1` 持续运动、`2` 每隔 10–30 秒间歇移动。模式切换会作废旧计时器、空间目标、完成事件和迟到行为；一次性移动不改写持久模式。
6. 共享自然语言矩阵覆盖普通聊天、停止、持续运动、间歇运动、一次性远移动和自定义动作。DeepSeek 与内置本地模型夹具均通过正式 Provider codec、AgentLoop、确认存储和 `FileToolService` 完成真实临时目录中的创建、移动及冲突失败验证。
7. P1 状态动作生命周期缺口已关闭：显式跨状态切换即使因冷却失败也会先撤销旧状态续选权；Main 确认角色进入搬运状态时同样撤销旧续选权，当前动作仍等待真实播放终态收敛。
8. P1 异步模式切换竞态已关闭：保存新模式前先以 revision 瞬态阻塞旧 Scheduler、直接运动入口、空间目标、状态生命周期和迟到完成事件；落盘失败保持原持久模式，并由 Scheduler 从暂停点恢复原策略。
9. P2 路径澄清续接已关闭：只有同代、紧邻且符合根内相对路径封闭形状的回复可以续接原文件任务；普通聊天会清理旧澄清，绝对路径、UNC、设备路径和 `..` 不会借用旧文件权限。
10. P3 提示预算缺口已关闭：模型公开角色目录受 `2,400` UTF-8 bytes 与 `24` 个状态/动作条目双预算，完整聊天 system 不超过 `4,800` UTF-8 bytes；默认状态及其真实动作优先，当前用户正文保持原样。云端与本地 Provider 使用相同裁剪结果。
11. 云端和本地流式响应共用同一个顶层正文投影器；纯文本降级、跨分片 Unicode 解码与嵌套隐藏字段跳过保持一致，重复顶层 `text` 键继续失败关闭。

## 3. 旧正式路径减法扫描

本轮按新规格扫描生产入口，没有发现需要删除的小规模旧正式实现：

- 生产公开角色目录已无扁平 `candidates`；其余同名变量是局部候选集合或 Provider API 字段，不属于已退役契约。
- 六字段严格 Schema 只用于约束模型建议；运行时已允许纯文本正文，并对隐藏字段逐项校验，不存在六字段整体失败关闭的正式路径。
- `expectedWriteOperation` 仅存在于规格与计划的退役说明，生产源码没有该硬约束。
- 旧 `{ kind: 'play', target: ... }` 只保留在拒绝型安全测试和 Main 内部显式动作 Gate；Provider 正式协议已经使用 `play_state`，两者不是同一公开入口。
- MCP 源码和持久化数据按项目安全规则保留，但生产源码图没有从正式入口导入 `src/main/mcp`，构建继续执行 MCP 生产边界校验。没有启用 MCP，也没有删除其保留数据。

因此本任务未删除代码或测试，避免把仍承担安全拒绝、Main 私有裁决或持久化兼容职责的路径误当冗余删除。
