# 日常使用内存优化验收

日期：2026-09-14。Windows，现有 worktree。依据[规格](../superpowers/specs/2026-09-14-desktop-steady-memory-design.md)与[计划](../superpowers/plans/2026-09-14-desktop-steady-memory.md)。用户要求 API 模式日常空闲尽可能降低、全部现有功能和效果保持，并最新明确 500 MB 不作为硬性阈值；本轮先不优化内置模型。没有修改模型实现、配置或资源，没有启动模型基准，没有执行 Git 写操作。

## 方法与边界

使用本机忽略目录 `.superpowers/sdd/2026-09-14-desktop-runtime-memory/dev-gpu-memory-probe.ts`。独立临时用户目录、默认正式角色、本地模型关闭，不读取真实配置或聊天，不发送 Provider 请求。开发模式为真实 `electron-vite dev`，不启用 E2E、不禁用 GPU；硬件加速、合成、栅格化、WebGL 均实际启用。

指标为 Windows `WorkingSetPrivate`，汇总本次 Electron Main 及其 Electron 后代，单位 MiB；Node/Vite 单列。指标不包含专用显存。每轮依次冷启动、打开设置、打开工作室、原生关闭两窗口；首末阶段各三样本，间隔五秒。原生关闭使用准确 PID 与合成标题定位 HWND，确认句柄仍存在、可见性为 false、页面未销毁。所有诊断进程均按本次捕获 PID 和启动参数核对归属后清理。

这套受控测量能比较同机同条件结果，不代表所有 DPI、角色、会话长度或长时间运行；CDP 附着可能影响后台页面状态，不把 `document.hidden` 当作原生隐藏证据。桌宠测量未强制 GC 或裁剪工作集。前轮软件栅格化冷启动数据继续只适用于[前轮验收](2026-09-14-desktop-runtime-memory-acceptance.md)，不能用它替代真实开发版日常内存。

此前一次未增加断开阶段的正式构建样本保留于 `production-gpu-1789363148549`，隐藏中位数 606.438 MiB；不将它与后来断开连接后的读数直接相减。最终仍保持八个 Electron 进程与五个页面的原有状态，没有销毁设置或工作室来换取数字。
