# 单屏移动回跳修复验收

日期：2026-09-12。Windows、Electron 43.5.0，当前单屏环境。依据[规格](../superpowers/specs/2026-09-12-pet-motion-jitter-design.md)与[实施计划](../superpowers/plans/2026-09-12-pet-motion-jitter-fix.md)。用户明确最终视觉验收由本人负责，本轮不继续扩大视觉采样范围。

用户随后实际测试并回复“没问题了！”，确认本轮单屏移动观感问题已解决，同时授权提交当前必要修改。因此本轮移动观感记为**用户人工反馈通过**；此反馈不扩展为其他设备、跨屏或整套历史人工清单均已验收。

## 录屏与根因

对用户指定的 11.566633 秒、2534×1506 录屏进行本地解码，以每秒 30 个时刻提取 346 次样本。前两秒头部白色轮廓宽度为 184～185 个录屏像素；0.302～0.335 秒相同动作帧向后约 7 像素，0.368～0.402 秒同样姿势再次向后约 5 像素。这证明抽动包含实际位置回退，不能由窗口尺寸已恒定推断运动已连续。后段鼠标提示会干扰轮廓提取，不将其异常宽度解释成角色变大。

正式组件及正式控制器的最小复现确认：Main 先移动窗口，Renderer 收到迟到快照后再使用负向 CSS 残差补偿。固定单帧、8/20 ms IPC 延迟、左右两个方向均能复现回跳，不需要动画换帧。

另一条真实组合复现确认：同一跑步动作自然续播时，播放修订号改变几何 binding 身份，重复布局落盘占用 FIFO；模拟 80 ms 设置保存后，1150/2250 ms 等时刻会跳过运动 tick。

## 修改与 RED → GREEN

- 删除 Renderer 的独立追赶类及 host CSS 二次位移，保留递增快照过滤、方向、锚点和生命周期。组件新回归先出现 3 个失败场景，每个出现 6 次反向步；修复后组件 **52/52 通过**。旧追赶专用测试退役，乱序/重复快照保护迁到真实组件测试。
- Main 保留连续小数位置，只在原生定位边界取整，原定时器采用约 60 Hz；旧 16 ms 整数积分会改变速度、丢失斜向短轴，回归先失败后修复。新增覆盖小数精度、DPI 回执、同步原生事件、停止、拖拽、几何重基与撤销、定位失败、无几何恢复。运动测试 **67/67 通过**。
- 几何 binding key 仅移除纯播放 `schedule.revision`；返回的 `actionRevision` 及角色/皮肤/动作/资源/方向身份保留。重复续播不再落盘，真实布局、权限校验和失败回滚不变。真实组合慢保存回归先失败后通过。
- 不修改作者素材、帧率、帧锚点、模型协议或状态三档含义，不增加依赖或 IPC。删除原重复追赶实现，复用正式数学、定时器与固定尺寸定位入口。
