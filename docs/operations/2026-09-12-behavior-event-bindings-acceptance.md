### 2026-09-12 原修复范围

模型先根据完整公开作者名称与描述，为九类情境选择合法状态动作配对；Main 保存当前实例的用途表。接收输入、授权等待、真实任务开始与终态直接驱动相应表现。逐轮模型只选择新反应、明确目标、长期背景或运动控制，不再生成活动条件、分数和调度时长。

- 输入处理期间保持思考，主回复结束才释放；提前返回的普通夸赞反应排在正文之后，不抢占或提前消耗思考期间的动画时间。
- 实际 Core 工作期间保持工作，授权和具体操作许可等待单独表示；成功开心、失败沮丧直接使用可信终态，取消不冒充失败。
- 一次反应遵守作者状态片段时长，可有多个动作循环；片段退出后不再因冷却结束重播。临时反应结束恢复有效背景与原运动模式。
- 五分钟未收到桌宠互动时应用已匹配的无聊背景；用途准备与自主重评时钟、额度分离。保留用户选择的休息等背景，真实互动才释放宿主拥有的无聊背景。
- 有效自主评估再次选择同一无聊背景时保留空闲来源，点击仍能退出；改成休息或用户明确选择时交接来源。任务状态快捷回复复用普通输入的取消与互动入口，不让旧反应回流，也不新增模型请求。
- 模式 0 禁止自动位移，模式 1 连续运动，模式 2 等待后再运动。聊天、任务、确认、拖拽与单次反应占用均参与调度；松手根据仍然有效的实际活动恢复。
- 冷启动首先等待当前角色的合法 Renderer 首帧，再允许自动运动。用途预热仍可提前完成；运动原有 1.5 秒首帧期限、单屏位移算法及尺寸逻辑没有放宽或重写。
- 远程主回复与普通表现继续并发；单槽 Qwen 使用已准备的思考表现先运行正文，随后做必要的普通表现选择。任务申请不额外占用 Qwen 槽，任务结果不再发第二轮表现推理。

删除旧活动匹配、任务终态表现请求、嵌套模型选择 Schema 与转换器，保留唯一 Engine 和仍使用的内部决策类型。默认素材、作者描述、文件 Core、主会话任务申请协议、授权及权限边界不变。没有新增依赖、部署或发布；用户在验收交付后明确授权提交本轮源码、测试与文档。
