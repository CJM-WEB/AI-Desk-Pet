# 本地大尺寸角色素材验收

日期：2026-09-11。环境：Windows、Node.js 24.18.0、Electron 43.5.0；当前工作树。依据：[规格](../superpowers/specs/2026-09-11-large-character-source-design.md)、[计划](../superpowers/plans/2026-09-11-large-character-source-plan.md)。本轮不执行 Git 写操作，不修改用户研究资料、安装版数据或官网链路。

## 实际改动

- 本地 PNG／WebP 源图不再受整图 4096 边长、32 MiB 单文件及每角色 512 MiB 总量限制；新导入、catalog 恢复、重建服务读取与源校验使用同一策略。
- 网格取消 64 行／列表单上限。大源图预览在上传 GPU 前按帧裁成小页；源图、编辑矩形、帧身份、时长、锚点保持不变。
- 编译使用唯一分页布局，不缩放帧；所有页按 SHA 去重、映射帧资源引用，几何绑定所有实际使用页的修订，随原事务一次发布。
- 移除单表现累计面积只能容纳一页的限制，保留单帧 4096、每动作 500 帧和单页矩形边界。共享角色压缩包及网站上传／扫描规则未改。

## 边界与未覆盖

图片格式本身、可用内存／磁盘、Electron 解码器和 GPU 能力仍有限；本轮不承诺无限物理容量，未进行数 GB 或极端帧数压力测试。当前仍完整解码源图、保留动作资源；分页限制单张画布，不等于流式解码。

Main 对合法 V3 继续校验清单、文件集合、长度和 SHA，不重新解码核对真实页尺寸或重算几何；这是调查发现的既有边界，已在规格明确，未伪称已强化。工作室编辑期间通过修订使旧编译结果失效，未新增立即打断底层解码的承诺。

真实桌面观感、安装版重建分发、不同硬件的大图容量：待用户人工确认或后续独立验收。原有研究改动保持原样。
