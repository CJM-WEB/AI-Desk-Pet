## 2. 已证明的不变量

1. 本地模型与云 Provider 使用同一 Main 工具与行为链；本地 Runtime 不持有文件或 PowerShell 权限。
2. 本地结构化聊天不接受思考标签或纯文本角色控制降级；文字流使用有界 SSE，工具回合保持完整结构化响应。
3. Vulkan 设备选择会枚举硬件并优先独显；温和预算只裁剪最旧完整回合，不截断当前用户输入。
4. 拖拽期间不切换静态播放器，不引入 scale；滚轮不改变桌宠尺寸或持久化档位。
5. 停止锁只禁止自主移动；停止状态可跨重启保持，后续明确移动仍能执行。
6. 文件创建、读取、检索、精确编辑、多文件补丁、移动与回收站删除均通过可信结果链；失败事实不能被模型正文覆盖。
7. OpenCode 不存在独立复制工具，其复制依赖 Shell。本项目已删除无法满足 Windows TOCTOU 回滚边界的试制 `copy_file`；明确复制请求由 Main 稳定拒绝，不进入普通聊天伪称成功。
8. 设置中的截图与剪贴板隐私占位项已经删除，旧设置只迁移这两个字段。
