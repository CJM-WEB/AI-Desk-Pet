用户最后明确要求“别处理额外内容，只负责聊天界面视觉层的重构”。据此停止角色、拖拽和模型业务的额外回归与问题处理，并撤除为这些额外工作增加的模型测试准备、响应脚本修补和诊断代码。以下只交付聊天视觉、获准的窗口控制、必要界面通信及对应验证。

## 交付范围

- 顶部默认隐藏；光标触顶先出现提示，点击后三球展开为选项、胶囊输入、发送／停止。整体可沿原方向收起。
- 选项包含新对话、历史、设置，保留菜单项目扩展结构。历史展开时输入整行下移，可滚轮查看正文；背景使用独立 Windows 原生 acrylic 层实现真实模糊。
- 普通回复显示为头顶自适应气泡，完整提交后 30 秒消失；悬浮或键盘聚焦才显示关闭按钮。长内容内部滚动，关闭不删除正文。
- 授权统一为“待授权操作”，左拒绝、右授权；按已确认约定，覆盖为“明确文件编辑操作”，左拒绝、右覆盖。点击正文展开原完整详情，按钮交回原处理器。
- 新气泡只有严格白名单展示 API，不订阅业务事件、不保存会话；过期展示点击被拒绝，展示故障保留原 chat 的确认入口。
- 模型调用、聊天处理、会话保存、文件执行、授权判定和桌宠行为决策保持不变。旧聊天布局、相邻窗口定位、专属 CSS 和未使用关闭组件已清理。
