## 6. 主 Agent 实际窗口观察

2026-07-22 在 Windows 实际窗口中观察到：

1. 桌宠窗口可见。
2. 点击桌宠后聊天窗口打开。
3. 关闭聊天窗口后，可见窗口列表由 2 个减少为 1 个，表明聊天使用原生隐藏路径，而不是只隐藏页面内容。

由于 Codex 窗口遮挡，本次观察没有完成聊天重新打开、真实鼠标拖动和系统托盘交互。这三项保持“待用户人工确认”，不得写为通过。本记录没有截图，也不以未保存的画面或推测补充结果。

## 7. 用户人工确认清单

请先准备专用测试目录，不要使用系统目录或真实重要数据，然后按顺序操作：

- [ ] 最小化 Codex，确认桌宠透明区域、置顶表现和托盘图标可见。
- [ ] 用真实鼠标拖动桌宠，确认窗口随鼠标移动且不会永久丢到屏幕外。
- [ ] 点击桌宠，确认聊天窗口打开。
- [ ] 关闭聊天窗口，再次点击桌宠，确认聊天重新打开且仍可正常输入。
- [ ] 从系统托盘分别执行“打开聊天”“打开设置”“显示/隐藏桌宠”，记录每项实际结果。
- [ ] 所有观察记录完成后，再决定是否从托盘点击“退出”。在记录完成前不要点击“退出”；退出会终止应用、桌宠和托盘进程。

任何一项与预期不符时，应记录操作步骤、实际表现和可复现条件，并将对应状态改为“失败”，不得将未执行项补记为通过。
