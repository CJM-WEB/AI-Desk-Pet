# 单屏移动回跳修复

日期：2026-09-12。依据用户在尺寸修复后提交的录屏及继续排查抽动的要求，沿用固定尺寸、三档运动和真实移动首帧门槛。本次恢复自然连续移动，不修改角色素材、帧锚点或模型选择。

规格边界见[单屏移动连续性修复规格](../specs/2026-09-12-pet-motion-jitter-design.md)，运行结果另记验收。

本轮实施与定向自动化已完成，用户已确认单屏移动观感问题解决；完整门禁限制与人工反馈见[实际记录](../../operations/2026-09-12-pet-motion-jitter-acceptance.md)。

## 证据与实现约束

- 用户录屏前两秒头部白色轮廓宽度为 184～185 个录屏像素；0.302～0.335 秒相同动作姿势却向后约 7 像素，0.368～0.402 秒再次回退。尺寸恒定不代表位置连续。
- 正式 Renderer 控制器以独立速度追赶 Main 的 50 ms 快照，再把差值加到已经移动的原生窗口上。受控 8 ms IPC 延迟的最小复现出现 15 次反向跳动；固定单帧亦可触发，无需动画换帧。
- 直接提高 Main 频率也不正确：当前从整数窗口位置重新积分，16 ms 节拍会使水平速度增大、斜向短轴丢失。必须保留连续位置，仅在原生边界量化。
- 同动作自然续播的 schedule revision 可能导致重复几何事务；只在真实复现证明后减少，保留角色、动作、方向、资源及 IPC 修订校验。

比较后采用一条位置链：Main 保留连续运动位置并以约 60 Hz 推进；Renderer 消费方向和坐标用于呈现、锚点，不再用另一套速度改变角色宿主位置。保留 Pixi 作者帧播放，不以修改帧率、缩放或逐帧对齐掩盖回跳。仅调节旧追赶速度仍存在异步窗口，不采用；新增预测协议或全屏窗口超出本次必要范围，不采用。

本次在移动位置补偿范围内替代 2026-09-01 固定尺寸规格第 4.3 节的“保留 Renderer 运动残差”；其动作级锚点、不启用 roundPixels 和固定尺寸继续有效。用户现行“消除抽动、删除冗余根因代码”要求作为本次修复依据，不恢复曾撤回的素材逐帧锚点方案。

## 失败、安全与清理

不新增 IPC、权限、依赖或持久化数据；录屏只在本地解码，诊断产物存入忽略目录。模型和角色原件不变；用户拖拽、停止、取消及几何事务继续由 Main 裁决，原生异常不得伪装成成功。删除旧补偿类和专用测试，不叠加另一套平滑器。无 Git 写操作，无批量删除，单屏之外不在验收范围。
