## Git 权限边界

- Codex 可以创建、修改文件并运行验证命令。
- 用户已经授权 Codex 在正式目录执行一次 Git 初始化；此后 Codex 不执行 `git add`、`git commit`、`git push`，也不创建分支或拉取请求。
- 用户使用 Fork 与 GitHub 验收变更并管理全部仓库状态。
- 每项任务以**用户验收交接点**结束，由用户决定是否以及何时提交。
- 面向人的文档、计划、说明和代码注释默认使用中文；文件名、命令、库名、协议字段和代码标识符保留英文。

## 完成规则

只有已批准 MVP 规格第 21 节中的每个功能与质量检查项，都有通过的自动测试或明确的 Windows 人工验收记录，第一阶段才算完成。
