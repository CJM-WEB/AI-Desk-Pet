# 单屏桌宠移动连续性修复规格

日期：2026-09-12。依据用户报告尺寸修复后仍抽动、提供真实录屏并要求继续解决的现行修复范围。本次只涉及单屏移动的执行精度和重复位置补偿，沿用已批准的三档运动、首帧准备和固定尺寸契约。

## 目标与证据

用户录屏相同动作帧在向右移动时发生反向偏移，而头部轮廓宽度基本恒定。正式代码可通过分离原生移动、IPC 到达与 RAF 时刻稳定复现：窗口已经前移，Renderer 后到的追赶残差又将角色向后平移。尺寸测试及内部累计路程不足以检测这个问题。

另一个正式组合复现证明，同一跑步动作每轮续播使几何 generation 改变，重复布局包含设置落盘；布局占用期间运动 tick 被跳过。纯播放轮次没有改变几何来源，却参与了布局身份。

目标是单向运动不出现程序制造的反向补偿，动作自然续播不因为相同几何重复落盘而停顿，较细节拍下速度和斜向位移保持准确。帧率、素材、动作级锚点、镜像、角色状态和模型协议均不修改；不保证所有设备的显示合成达到固定帧间隔。

## 唯一位置链

Main 的 `CharacterMotionService` 保存连续小数位置，并复用原 `advanceMotion` 积分。窗口定位边界才转换为整数，继续调用固定尺寸定位入口。移动计时采用约 60 Hz；自主判断等既有低频调度不变，不增加模型调用。

Renderer 删除独立速度追赶及 CSS 平移，保留递增修订检查、方向同步、作者帧播放和桌面锚点投影。锚点以 Main 位置和当前播放器局部布局计算。它不再拥有第二条桌面位移轨迹。

直接提高旧整数积分频率会使速度偏差扩大甚至丢失斜向短轴，不能单独实施。调整第二追赶器速度仍不能消除跨进程先后顺序问题；不引入新的预测协议、原生桥或覆盖全屏的窗口。

## 生命周期与失败

新目标、停止、用户拖动与几何缺失按真实窗口位置同步连续位置。几何事务移动原点时目标和连续位置同时重基；未发生的事务失败只撤销自己的重基。原生定位可能同步产生回执，连续位置须在调用前提交；合法 DPI 往返取整不反馈成下一帧积累误差，真实超容差偏移沿用原纠偏边界。原生定位失败不发布成功快照，不遗留本次预期回执或虚增进度。

几何 binding 身份仍由角色加载、皮肤、动作、资源和方向组成；播放轮次不再改变其 generation。每次返回的 `actionRevision` 仍保留真实当前修订，Authority 的过期/冲突检查和真实布局 FIFO 不放宽。

## 安全、迁移与验收

不新增 IPC、权限、依赖、遥测或持久化字段；用户录屏只在本地诊断。删除原 Renderer 追赶类和其专用插值测试，保留共用数学与锚点工具。角色素材和创作原件不迁移，无批量文件删除和 Git 写操作。

先以真实组件、固定单帧及不同方向/IPC 延迟验证屏幕合成位置回退，再修复。Main 回归覆盖高频水平/斜向速度、DPI、拖拽、停止、几何重基和失败；真实组合覆盖慢持久化时自然续播不会反复布局。Electron 验证全程窗口/Canvas 尺寸、原生位置、宿主偏移及三档行为。测试结果和未覆盖项另记验收，不把自动化等同于人工观感。
