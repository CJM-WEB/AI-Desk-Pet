# AI Pet 官网剩余章节与视觉统一设计

## 1. 目标

在现有五章节推拉官网基础上完成以下工作：

1. 统一五个章节的背景、图层、标题倾斜和动效语言。
2. 修复重点内容可能被文件粒子遮挡、章节滚轮灵敏度不足的问题。
3. 重构下载章节和捐款章节的视觉与交互。
4. 正式实现“AI Pet 介绍”章节。
5. 正式实现“用户反馈与建议箱”章节。
6. 为当前无服务器环境提供浏览器本地持久化，并为未来服务端 API 保留稳定接口。

参考图仅用于理解布局、遮挡关系和信息组织，不直接复制 Windows 界面或参考图样式。最终视觉必须延续现有首页的浅灰、黑色轮廓、蓝色状态强调、文件图标和推拉镜头语言。

## 2. 不在本轮范围

- 不实现真实服务端、数据库、登录系统或跨设备同步。
- 不验证 PayPal、微信或支付宝的真实支付结果。
- 不修改 Windows 安装包发布流程或现有发行清单。
- 不直接嵌入参考图截图作为功能面板。
- 不引入新的 3D、WebGL 或重型状态管理框架。

## 3. 全局视觉系统

### 3.1 六阶放射背景

新增共享 `ChapterBackdrop`。背景由六个不规则放射面片构成，固定使用：

- `rgb(200, 200, 200)`
- `rgb(205, 205, 205)`
- `rgb(210, 210, 210)`
- `rgb(215, 215, 215)`
- `rgb(220, 220, 220)`
- `rgb(225, 225, 225)`

五个章节使用同一颜色和构图规则，但放射中心、旋转角度和面片比例略有差异，使章节切换具有空间连续性，又能区分场景。背景只使用 CSS 面片或伪元素，不使用额外位图。

### 3.2 图层契约

所有章节遵守同一图层令牌：

| 图层 | 用途 | 层级 |
| --- | --- | --- |
| 背景 | 六阶灰色面片 | 0 |
| 光场 | 首页鼠标灰色光场 | 10 |
| 文件 | 随机文件图标 | 20 |
| 功能 | 章节功能面板与列表 | 40 |
| 重点 | Logo、标题、主要按钮、滚筒当前项 | 60 |
| 预览 | 跟随鼠标的说明框 | 80 |
| 模态 | 付款码、反馈列表、投稿编辑器、确认框 | 100 |

重点内容始终高于文件粒子。文件粒子不得覆盖文字、阻断按钮点击或成为功能面板上方的意外命中目标。

### 3.3 标题倾斜

抽出共享 `PointerTiltText`，复用首页品牌倾斜算法。以下内容使用同一规则：

- 首页 Logo 与 `AI Pet`
- 下载章 `AI PET DESKTOP` 与“选择你的平台”
- 介绍章中央 `AI Pet`
- 反馈章“倾听你的声音，打造属于你的 Pet”
- 捐款章“助力开发，你便也是我不可或缺的参与者”

倾斜只使用 `transform`，角度受限，不能离开原命中区域。触屏、减少动态效果和静态回退模式下倾斜归零。

### 3.4 章节滚轮

普通带刻度鼠标连续滚动约 3 至 5 个刻度即可切换一个章节。滚轮突发期间持续累计，停止后再吸附到相邻章节。

必须保持：

- 一次输入突发最多移动到相邻章节。
- 小幅误触最终回到当前章节。
- 边界方向输入不会将进度卡在小数状态。
- 下载、支付、反馈列表等局部输入不会冒泡到章节控制器。
- 触屏与键盘行为继续遵守相邻章节限制。

## 4. 共享文件视觉层

文件粒子按章节使用配置化内容源：

| 章节 | 文件粒子 | 光场 | 预览内容 |
| --- | --- | --- | --- |
| 首页 | 开启 | 灰色 | 现有文件内容 |
| AI Pet 介绍 | 关闭 | 关闭 | 功能区域自有说明 |
| 下载 | 开启 | 关闭 | 现有文件内容 |
| 反馈建议 | 开启 | 关闭 | 随机反馈或建议 |
| 捐款 | 开启 | 关闭 | 现有文件内容 |

`SharedVisualLayers` 继续持有唯一文件粒子实例、预览层和错误回退边界。内容源通过配置或适配器注入，不能在粒子组件中写死章节判断。

反馈章节中的每个粒子在生成时绑定一条反馈或建议快照。粒子生命周期内内容保持稳定；粒子消失后重新生成时重新随机选取。

## 5. 下载章节

### 5.1 视觉

- 移除左右青蓝色背景。
- 使用共享六阶放射背景。
- 复用首页随机文件图标与文件预览交互。
- 平台滚筒和当前下载操作保持重点图层。
- 两行标题使用共享倾斜效果。

### 5.2 两侧说明

桌面端：

- 移除可见箭头按钮、点击锁定和 `aria-pressed` 状态。
- 左右边缘提供弱提示感应区。
- 指针悬停或键盘聚焦时临时展开对应说明。
- 移开或失焦时自动关闭。
- FAQ 与安装须知仍互斥，并保持先关闭当前侧、再打开目标侧。

移动端：

- 保留可触摸提示控件。
- 轻触展开，点击空白处关闭。
- 该移动端例外不改变桌面“仅悬停”的规则。

平台滚筒、真实 Windows 链接、macOS 敬请期待、SHA-256 和配置扩展能力保持不变。

## 6. 捐款章节

- 使用共享六阶放射背景。
- 删除黄色鼠标光圈。
- 保留文件粒子与现有内容预览。
- 标题使用共享倾斜效果。
- 支付滚筒扩展为配置驱动的三项：
  - 微信：`/WechatPay.jpg`
  - 支付宝：`/Alipay.jpg`
  - PayPal：`/Paypal.jpg`
- 三种支付方式使用相同的当前项、非当前项、付款码 Portal、缺图回退和焦点恢复行为。

`Paypal.jpg` 当前存在于主工作区 `apps/website/public`。实施时需要确认该资源已进入实际开发工作树和最终提交范围，不允许生成替代付款码。

## 7. AI Pet 介绍章节

### 7.1 区域组成

章节包含中央标题和五个非对称重叠区域：

1. 桌面整理：使用现有文件图标组成桌面缩略视图。
2. 聊天陪伴：消息流、状态反馈和快捷问题。
3. 系统守护：安全状态、扫描结果和权限提醒。
4. 文本编辑：编辑工具栏、正文区域和保存状态。
5. 文件管理：目录树、文件列表和快捷整理操作。

功能示意使用 React、CSS、Lucide 图标和现有位图文件图标构建，不直接嵌入参考截图，不手绘重复 SVG。

### 7.2 入场和遮挡

进入章节时从后层到前层依次出现：

1. 系统守护
2. 文件管理
3. 文本编辑
4. 聊天陪伴
5. 桌面整理
6. 中央 `AI Pet`

每项从较大比例和低透明度进入正常尺寸，复用章节推拉的空间语言。相邻项目错峰约 80 至 110 毫秒。离开章节时按相反方向快速收束。

### 7.3 交互

- 中央标题及周围为安全区，不触发功能区域。
- 桌面端仅使用悬停和键盘聚焦，不提供点击锁定。
- 活动区域提升到最高功能层，其他区域降低清晰度并停止接收指针。
- 跟随鼠标的说明框展示功能名称、润色后的能力说明和对应界面示意。
- 离开或失焦后恢复原遮挡顺序。
- 移动端轻触锁定，点击其他区域或空白处恢复。
- 说明框复用现有预览定位算法并限制在视口内。
- 减少动态效果模式直接显示最终布局。

## 8. 用户反馈与建议箱

### 8.1 主场景

标题为“倾听你的声音，打造属于你的 Pet”，使用共享倾斜效果。中央滚筒配置为：

1. 用户反馈
2. 更新建议
3. 新建投稿

滚筒复用捐款章的循环索引和视觉模型，但内容、按钮语义和打开结果独立配置。

### 8.2 反馈与建议列表

点击“用户反馈”或“更新建议”打开全屏 Portal 查看层：

- 背景模糊。
- 内容使用纵向错层列表，不在卡片中嵌套卡片。
- 每条显示昵称、正文、发布时间、点赞数和点赞按钮。
- 同一浏览器对同一条记录只能点赞一次，可取消点赞。
- 默认按点赞数降序，同票按发布时间降序。
- 列表内部滚动属于局部输入，不切换章节。
- 点击遮罩、关闭按钮或按 `Escape` 退出。
- 打开后焦点进入查看层，关闭后返回触发按钮。

### 8.3 新建投稿

点击“新建投稿”打开半透明编辑面板：

- 背景使用比查看层更强的模糊。
- 可选昵称；为空时显示“匿名用户”。
- 浏览器生成并保存本地匿名 ID。
- 昵称去除首尾空格后最多 24 个字符。
- 正文去除首尾空格后限制为 10 至 1000 个字符，并提供实时计数和就地错误提示。
- 发布类型使用“用户反馈 / 更新建议”分段控件。
- 发布成功后立即写入本地仓储、关闭编辑器并进入对应列表。
- 无内容时点击遮罩直接关闭。
- 有未保存内容时点击遮罩、取消或 `Escape`，显示“放弃未发布内容？”确认。
- 确认放弃后关闭；取消放弃后恢复编辑焦点。

### 8.4 演示数据与粒子预览

首次打开内置反馈和建议各 6 条“官方示例”。示例内容可集中替换，并参与列表展示和粒子随机预览。

用户数据存在时与示例共同排序。清除浏览器站点数据后恢复官方示例。

## 9. 数据模型与持久化

### 9.1 记录模型

每条持久化反馈或建议包含：

- `id`
- `kind`：`feedback` 或 `suggestion`
- `authorId`
- `authorName`
- `content`
- `likeCount`
- `createdAt`
- `updatedAt`
- `source`：`official-example` 或 `local-user`

当前浏览器已点赞的记录 ID 使用独立集合保存，展示时派生
`likedByCurrentBrowser`。本地模式不声称具备跨设备防刷能力。

### 9.2 仓储接口

UI 只依赖 `FeedbackRepository`：

- `list(kind)`
- `create(input)`
- `toggleLike(id, localUserId)`
- `subscribe(listener)`

当前使用 `LocalStorageFeedbackRepository`；未来服务端实现 `ApiFeedbackRepository`，UI 和章节交互不需要重写。

### 9.3 容量与裁剪

反馈和建议分别最多保留 1000 条。每次新增或数据迁移后分别裁剪：

1. 点赞数高者优先保留。
2. 点赞数相同时，`updatedAt` 较新者优先。
3. 仍相同时使用稳定 `id` 排序，保证结果可测试。

列表展示使用相同排序规则。官方示例属于默认数据，不应挤占用户数据的保留优先级；当真实用户数据达到上限时，示例可不进入持久化数组。

### 9.4 错误与同步

- JSON 解析、版本迁移或配额写入失败时，不让章节崩溃。
- 解析失败时回退到官方示例，并显示非阻断状态提示。
- 写入失败时保留当前编辑内容并显示可重试错误。
- 使用 `storage` 事件同步同一设备的其他标签页。
- 服务端版本上线后，容量约束仍由服务端最终执行，客户端只用于展示和乐观交互。

## 10. 响应式与可访问性

- 保持 `760px / 761px` 断点契约。
- 桌面悬停功能必须提供键盘聚焦等价行为。
- 移动端不得依赖悬停，使用轻触锁定和空白处关闭。
- 所有按钮和触摸目标至少 44×44 像素。
- 模态层具有 `role="dialog"`、`aria-modal`、标题关联、焦点循环和焦点恢复。
- 表单使用可见标签，不使用仅占位符标签。
- 文本与灰阶背景对比度不低于 4.5:1。
- 禁止 `vw` 字号、负字距、横向页面滚动和文字遮挡。
- `390×844`、`375×667`、`760×900`、`761×900`、`1440×900`、`1920×1080`、`568×320` 均需验证。

## 11. 动效与生命周期

- 章节、面板和列表动效只使用 `transform` 与 `opacity`。
- GSAP 使用组件根节点作用域、时间线和明确 cleanup。
- 指针跟随使用 `quickTo` 或现有等价实现，避免每次移动创建新 tween。
- 窗口失焦、页面隐藏、静态回退和减少动态效果时停止持续动画、RAF 和无意义过渡。
- 最终卸载期间不得向父组件上报状态或触发已卸载树更新。
- 动效初始化或清理失败进入统一静态回退，核心文本、下载链接、支付按钮和反馈表单仍可用。

## 12. 测试与成功标准

### 12.1 单元与组件测试

- 图层令牌和重点内容层级。
- 六阶背景配置。
- 滚轮灵敏度、突发累积、吸附和边界恢复。
- 标题倾斜有限值、视口变化和减少动态效果。
- 介绍面板进入顺序、桌面悬停恢复、移动锁定和安全区。
- 支付三项配置和 PayPal 图片映射。
- 本地仓储解析、创建、点赞、取消点赞、跨标签同步和错误回退。
- 两类数据分别裁剪到 1000 条并优先保留高赞记录。
- 文件粒子生成时绑定内容，重生后重新随机选取。
- 投稿未保存确认、验证错误和写入失败保稿。

### 12.2 浏览器测试

- 所有重点文字和按钮高于文件粒子且可点击。
- 普通鼠标 3 至 5 个刻度切换一章，不跳章。
- 下载桌面悬停展开、移动轻触展开、移开或点空白恢复。
- 介绍五区域错峰出现、悬停置顶、说明框跟随且不越界。
- 反馈列表、点赞切换、刷新持久化、投稿和放弃确认。
- 三种付款码正常加载，缺图回退仍可关闭。
- 各目标视口无横向溢出、遮挡和裁切。
- 减少动态效果、页面失焦、初始化失败和静态回退完整。
- 控制台无未处理错误，测试服务器使用隔离端口且退出后无残留进程。
