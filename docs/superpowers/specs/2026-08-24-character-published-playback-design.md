# 角色发布播放参数设计

## 目标

角色工作台对当前皮肤、当前动作设置的播放倍速与素材水平反转，在“编译并发布”后进入正式 V2 角色清单，并由实际桌宠播放器消费。重新选择角色、刷新角色列表或重启桌面端后，已发布参数仍然有效。

## 非目标

- 不改变播放、暂停、当前帧、深色预览背景、锚点显示和状态巡游等工作台临时预览状态。
- 不把 `action.direction` 改作素材方向；该字段继续表示动作适用方向。
- 不烘焙、复制或重写图片资源，不引入新的运行时、依赖、MCP 或脚本能力。
- 不改变动作循环策略；循环仍由正式动作定义的 `loopPolicy` 决定。

## 现状证据

- `PreviewControls.tsx` 只把 `speed` 与 `direction` 写入 React 预览状态。
- `character-workshop-store.ts` 编译表现时只复制帧率、锚点、区域、几何与帧，没有复制倍速或反转。
- `legacy-runtime-projection.ts` 只投影 `fps` 与动作定义字段。
- `PixiCharacterPlayer` 实际播放与切换方向时都固定传入 `speed: 1`。

因此预览可见的倍速与反转不会进入正式发布链路，实际桌宠只能使用默认播放速度和运动方向。

## 方案

### 正式契约

在每个 `CharacterActionPresentationV2` 上增加两个可选字段：

- `playbackRate`: 有限数值，范围 `0.25` 至 `2`，表示相对于素材帧时间的播放倍速。
- `mirrorX`: 布尔值，表示在运行时运动方向基础上额外水平反转素材。

字段属于“皮肤 × 动作”的表现层，因为不同皮肤和动作的素材原始朝向、适合节奏可以不同。旧 V2 清单、V1 转换结果和没有显式设置的草稿采用 `playbackRate = 1`、`mirrorX = false`，无需迁移文件。

V2 发布清单编译时保留这两个字段；旧播放器投影把它们带入 `ActionClip`。字段仍由严格 Schema 校验，非法值不能进入发布版本。

### 工作台语义

倍速滑块和“切换左右方向”继续即时更新预览，同时把结果写入当前皮肤、当前动作的表现：

- 预览 `speed` 对应 `playbackRate`。
- 预览 `direction === 'left'` 对应 `mirrorX = true`，`right` 对应 `false`。

切换动作或皮肤时，预览倍速和方向从解析后的表现恢复；播放状态、当前帧等临时状态不持久化。若当前皮肤通过回退继承另一皮肤的表现，首次修改时沿用现有规则克隆精确覆盖，不能改写来源皮肤。

### 实际播放器

实际播放速度使用 `action.playbackRate ?? 1`，不再固定为 `1`。播放器传给 Pixi 场景的有效方向采用异或语义：

| 运动方向 | `mirrorX` | 有效素材方向 |
| --- | --- | --- |
| right | false | right |
| left | false | left |
| right | true | left |
| left | true | right |

方向切换重建当前动作时必须继续使用同一播放倍速和反转规则，并尽量保留当前帧。Pixi 场景仍只接收已裁决的有效方向，锚点、布局、像素命中和碰撞区域因此与最终画面保持同一方向。

## 数据流

`PreviewControls` → `CharacterWorkshopView` → `updateCurrentAction` → V2 草稿表现 → 编译后的 V2 正式清单 → `legacy-runtime-projection` → `ActionClip` → `PixiCharacterPlayer` → `PixiCharacterScene`。

运行时只读取已发布清单，不读取工作台 React 状态。发布完成后沿用现有角色列表刷新与当前角色重载路径，不新增旁路状态。

## 安全、兼容与失败处理

- 新字段仅是受限数值和布尔值，不扩大角色包、Renderer 或 Agent 权限。
- MCP 运行时、Agent 和 Renderer 保持禁用。
- 非法倍速由 V2 与旧投影 Schema 拒绝；界面仍把滑块限制在 `0.25` 至 `2`。
- 编译或发布失败时不宣布成功，实际桌宠继续使用上一份成功发布版本。
- 旧角色清单省略字段时保持原有速度和方向，避免强制迁移与包体膨胀。

## 删除与替代范围

- 删除实际播放器中两处固定的 `speed: 1` 正式路径。
- 删除倍速和方向只停留在预览状态的旧绑定方式，替换为“即时预览 + 正式草稿表现”单一路径。
- 不删除其他预览专用状态，不新增第二套角色播放器。

## 自动化测试

1. V2 Schema 接受边界值并拒绝越界/非有限倍速，兼容字段缺失。
2. 编译保留 `playbackRate` 与 `mirrorX`，旧投影保留字段并提供默认行为。
3. 工作台修改倍速/方向后草稿变脏；切换动作或皮肤后从表现恢复；编译发布输入包含字段。
4. 实际播放器首次播放和方向切换都使用发布倍速；四种方向组合满足异或表。
5. 运行角色相关定向测试、类型检查及 `pnpm verify:characters`。

## 人工验收

用户负责最终总体验验收。建议至少发布两个视觉明显的动作：一个设置非 `1` 倍速，一个设置反转；确认实际桌宠立即刷新，并在切换状态、移动方向及重启桌面端后仍保持发布效果。
