# 官网章节平滑滚动、吸附与支持页按钮景深设计

## 1. 目标

本次优化仅调整官网视觉交互，不修改桌面端、桌宠角色、Agent、文件工具或 Electron 相关内容。

需要解决两个问题：

1. 当前滚轮事件直接修改章节显示进度，普通鼠标滚轮会呈现按档位跳变的视觉效果；需要改为连续、平滑、与刷新率无关的过渡。
2. 当前章节稳定后缺少足够的停留保护，用户容易被滚轮惯性带离页面；需要增加明确的吸附、惯性隔离和新手势解锁机制。
3. 最后一页左右两组循环按钮虽然已有位移、缩放和层级变化，但后层按钮缺少景深模糊；需要让遮挡关系更加清楚。

## 2. 范围

### 2.1 包含内容

- 调整官网全局滚轮进度控制与章节吸附行为。
- 为章节切换建立目标进度与显示进度分离机制。
- 增加滚轮停止检测、吸附动画、800ms 锁定和新手势阈值。
- 保留单次输入最多只到相邻章节的边界。
- 为最后一页左侧反馈按钮组和右侧支付按钮组增加统一景深模糊。
- 补充纯模型、控制器、组件、着色器契约和浏览器端测试。

### 2.2 不包含内容

- 不修改 `apps/desktop`。
- 不修改 `packages/agent-core`、`packages/character-runtime`、`packages/character-assets` 或 `packages/file-tools`。
- 不修改桌宠角色、桌面交互、Agent、MCP 或文件操作能力。
- 不调整网站章节内容、章节顺序、投稿流程、审核流程、下载发布状态或 CloudBase 接口。
- 不引入新的动画库、状态管理库或滚动框架。
- 不重做最后一页的布局、按钮文案或业务行为。

## 3. 已确认的交互决策

### 3.1 连续滚动

滚轮事件不再直接写入画面显示进度，而是更新目标进度。唯一的动画帧循环根据经过时间让显示进度连续追赶目标进度。

该机制必须满足：

- 普通鼠标滚轮不再按档位产生明显跳帧。
- 触控板仍保持连续跟手。
- 平滑速度按帧间时间计算，不依赖固定 60Hz。
- 快速或巨大的单次输入不能跨越相邻章节。
- 章节组件继续只消费现有 `progress`，不分别实现滚动平滑逻辑。

### 3.2 停止与吸附

最后一次有效全局滚轮输入后 120ms 内没有新输入，控制器选择最近的整数章节作为吸附目标。

吸附使用减速缓动，固定时长为 380ms。吸附越接近章节中心速度越慢，结束时显示进度和目标进度必须精确等于章节整数索引，不保留浮点残差。

### 3.3 800ms 锁定

吸附完成后立即进入 800ms 锁定期：

- 锁定期间所有全局滚轮输入均被吸收。
- 锁定期间的输入不计入后续解锁阈值。
- 锁定用于隔离鼠标滚轮和触控板在吸附后继续发送的残余惯性。
- 首页向上和末页向下的越界输入同样被吸收，不产生抖动。
- 锁定只隔离滚轮惯性；键盘、导航按钮和独立触摸手势属于明确导航，不受滚轮锁定阻断。

### 3.4 新手势解锁

800ms 到期并不立即允许滚轮离开页面。控制器必须观察到至少连续 120ms 没有滚轮输入，再进入新手势准备状态；若惯性输入仍在继续，则从最后一次输入重新计算这段静止时间。

新手势按规范化后的同方向 `deltaY` 累计：

- 累计阈值为约 240px，对普通鼠标约为 2–3 格有效滚动。
- 未达到阈值时页面保持完全吸附，显示进度不变化。
- 达到阈值后进入连续跟随状态，并从当前章节开始更新目标进度。
- 累计期间方向反转时清空原方向累计，并从新方向重新累计。
- 到达首页或末页边界时，不为越界方向建立可释放的累计量。

### 3.5 其他输入方式

- 上下导航按钮、方向键和 Page Up/Page Down 继续一次切换一个相邻章节。
- 触摸滑动继续使用一次有效手势切换一个相邻章节。
- 键盘、按钮和触摸切换完成后同样进入 800ms 稳定锁定，保持不同输入方式的章节停留一致。
- 标记为 `data-input-scope="local"` 的滚轮输入继续由弹窗、滚筒等局部组件优先处理，不进入全局章节状态机。

## 4. 状态模型

全局章节滚轮使用四种内部状态：

```text
resting
  当前章节稳定，尚未进入新的滚轮手势

locked
  吸附或程序化导航完成后的 800ms 惯性隔离期

arming
  锁定结束且已经确认滚轮静止，正在累计新手势阈值

tracking
  新手势已经越过阈值，目标进度连续接收滚轮输入
```

状态流转如下：

```text
resting
  → 首次有效滚轮输入
arming
  → 同方向累计达到 240px
tracking
  → 120ms 无新输入
吸附动画
  → 到达整数章节
locked
  → 800ms 到期且滚轮已经静止
arming
```

键盘、按钮和触摸可以从稳定状态直接启动相邻章节吸附动画；动画结束后统一进入 `locked`。

## 5. 代码架构

### 5.1 `useWebsiteController`

`apps/website/components/website-experience/use-website-controller.ts` 继续作为浏览器事件和生命周期拥有者，负责：

- 注册和清理滚轮、键盘、指针、焦点及可见性监听器。
- 维护显示进度、目标进度、稳定章节和滚轮状态引用。
- 启动唯一的 `requestAnimationFrame` 进度循环。
- 安排和取消 120ms 停止检测。
- 执行章节吸附并管理 800ms 锁定计时。
- 在暂停、静态回退和初始化失败时收敛到稳定章节。

对外的 `progress`、`settledIndex`、`isChapterTransitioning` 和 `goToAdjacent` 接口保持不变，避免修改各章节组件。

### 5.2 `chapter-model`

`apps/website/components/website-experience/chapter-model.ts` 承担可独立测试的纯计算：

- 规范化滚轮单位。
- 将目标进度限制在稳定章节的相邻范围内。
- 根据帧间时间计算显示进度的下一步平滑值。
- 选择最近吸附章节。
- 计算吸附缓动值。
- 累计解锁距离并处理方向反转。
- 判断进度是否足够接近目标并安全收敛。

浏览器计时器、动画帧编号和事件对象不得进入纯模型。

### 5.3 配置

滚轮体验参数集中维护，避免散落魔法数字：

- 停止检测：120ms。
- 吸附时长：380ms。
- 吸附后锁定：800ms。
- 新手势解锁阈值：240px。
- 目标进度追赶：采用指数阻尼，时间常数为 90ms；单帧时间差最多按 50ms 计算，防止恢复焦点或严重掉帧后突然跨越大段进度。
- 进度收敛阈值：目标差小于 0.0005 时直接写入目标值并停止该段追赶。

实现计划必须先用失败测试锁定最终参数，再编写生产代码。

## 6. 最后一页按钮景深

### 6.1 应用范围

统一应用于：

- 左侧的建议、反馈、创建投稿按钮组。
- 右侧的微信、支付宝、PayPal 按钮组。

两组继续共用现有循环索引、相对距离和按钮视觉模型。

### 6.2 景深规则

- 当前活动按钮：`0px` 模糊，保持完全清晰。
- 相邻后层按钮：`2.5px` 模糊。
- 最深后层按钮：`5px` 模糊。
- 位移、缩放、透明度、层级和模糊使用同一段约 420ms 的减速过渡。
- 新按钮前移时逐渐恢复清晰，旧按钮后移时逐渐失焦。
- 只有当前活动按钮可以执行点击操作。
- 键盘焦点只落在当前可操作按钮，模糊按钮不获得交互焦点。

### 6.3 WebGL 实现边界

最后一页可见的玻璃和文字由 `LiquidGlassHome` 的 WebGL 着色器绘制，透明 DOM 按钮只承担点击、键盘和无障碍语义。因此不能只在 `.glassButton` 上增加 CSS `filter`。

景深由现有活动索引和按钮相对距离直接派生：

- React 侧不新增逐按钮模糊状态。
- 着色器根据现有左右活动索引计算每个按钮的景深权重。
- 后层按钮文字采用有限的多点柔化采样。
- 后层玻璃轮廓适度软化，但不能使整个画布或当前按钮失焦。
- 当前按钮继续使用清晰采样，避免文字发虚。

静态回退或 WebGL 不可用时，保留缩放、透明度和层级来表达前后关系，核心按钮仍可操作。

## 7. 暂停、降级与错误处理

- 统一处理像素、行和页面三种滚轮 `deltaMode`，防止不同设备输入量级失真。
- 非有限 `deltaY` 视为无效输入，不污染累计量或进度。
- 标签页隐藏或窗口失焦时暂停动画帧，取消停止检测并清空未完成的滚轮手势。
- 页面恢复时收敛到最近章节，不继续消费离开前的惯性。
- 初始化、动画帧或监听器注册失败时沿用现有静态回退。
- 静态回退不能停留在两个章节之间。
- 组件卸载时必须回收动画帧、停止计时器、锁定计时器和全部监听器。
- 局部弹窗及局部滚筒输入不能被全局控制器拦截。

## 8. 减少动态效果

启用 `prefers-reduced-motion` 时：

- 不运行连续追赶和长时间吸附动画。
- 达到新手势阈值后直接切换到相邻章节。
- 仍保留 800ms 惯性隔离和新手势阈值，防止误切页。
- 最后一页按钮切换不播放连续位移动画，但切换完成后的模糊、缩放和层级关系仍保留。
- 所有语义、焦点和操作能力保持可用。

## 9. 测试设计

### 9.1 纯模型测试

- 四种滚轮状态的合法转换。
- 120ms 停止条件。
- 800ms 锁定到期前后的输入行为。
- 240px 同方向累计阈值。
- 累计期间方向反转后的重置行为。
- 像素、行和页面滚轮单位换算。
- 非有限值、超大输入和章节硬边界。
- 时间归一化平滑追赶和吸附收敛。
- 单次输入最多到相邻章节。

### 9.2 控制器测试

- 滚轮只更新目标进度，显示进度通过动画帧连续变化。
- 普通鼠标档位输入不会一次直接跳到目标显示值。
- 停止 120ms 后自动吸附到最近章节。
- 锁定期间残余惯性不改变显示进度或累计量。
- 锁定结束但未出现滚轮静止时不解锁。
- 新主动手势达到阈值后才开始离开章节。
- 页面隐藏、窗口失焦、静态回退和卸载正确清理资源。
- 键盘、导航按钮、触摸和局部输入优先级保持回归通过。

### 9.3 景深测试

- 活动按钮模糊为 0。
- 相邻后层按钮模糊为 2.5px。
- 最深后层按钮模糊为 5px。
- 左右两组使用同一视觉模型。
- 活动索引切换时层级、缩放、透明度和模糊方向一致。
- 只有活动按钮可以触发业务操作。
- 着色器包含按按钮景深执行的有限柔化采样，且当前按钮保持清晰路径。

### 9.4 浏览器与视觉验收

- 使用普通鼠标滚轮检查章节变化连续性。
- 使用触控板检查跟手性和惯性隔离。
- 每个章节吸附后，残余惯性不能直接带走页面。
- 800ms 后必须使用新的约 2–3 格滚动才能离开。
- 快速滚动不能跨越中间章节。
- 最后一页左右两组按钮在切换前、中、后均具有正确景深。
- 检查后层文字没有重影，活动按钮没有模糊，整个 WebGL 画面没有被错误柔化。
- 检查减少动态效果、窄屏和静态回退。

## 11. 完成标准

- 普通鼠标和触控板驱动的章节视觉连续，不呈现明显的逐档跳帧。
- 停止滚动后页面稳定吸附到最近章节。
- 吸附完成后的 800ms 内不会被残余惯性带离。
- 锁定结束后必须通过新的约 240px 主动滚动手势才能离开。
- 任意快速输入最多进入相邻章节。
- 最后一页左右两组按钮的后层均有清楚、连续且不过度的景深模糊。
- 当前按钮始终清晰、可聚焦且可操作。
- 现有章节内容、局部交互、键盘、触摸、静态回退和减少动态效果能力不退化。
- 不修改或影响任何桌宠与桌面端模块。
