# AI Pet 角色命中、拖拽、实时预览与提示层修复设计

> 文档状态：已确认设计，待用户审核规格文件  
> 产品名称：`AI Pet`  
> 目标平台：Windows 10/11  
> 基准日期：2026-07-29  
> 关联设计：[角色工作室与序列帧角色系统设计](./2026-07-27-ai-pet-character-workshop-design.md)

## 1. 目标

本设计修复第一版角色运行时与角色工作室中的四类问题：

1. 透明桌宠窗口的完整矩形区域会阻挡底层文件、桌面和应用交互。
2. 角色本体不能拖拽，只有本体外围的窗口空隙可以拖拽。
3. 工作台的自动保存成功反馈与页面横幅重复。
4. 工作台只有预览控制器，没有真正渲染当前草稿。

完成后，只有当前动画帧中实际可见的角色像素能够接收桌宠交互；左键只用于拖拽，右键只用于打开现有桌宠菜单。工作台直接预览当前内存草稿，并通过右上角临时提示层反馈操作结果。

## 2. 已确认决策

1. 角色使用逐帧 Alpha 像素命中，不使用整个窗口、帧包围盒或配置矩形作为主要命中范围。
2. Alpha 大于 `16/255` 才视为可见角色像素；Alpha 小于或等于该值时鼠标穿透。
3. 透明光晕和完全透明空洞均不得阻挡底层应用。
4. 左键只用于拖拽角色，不再打开聊天。
5. 左键单击和双击扩展状态暂不处理；保留扩展状态协议和模块边界，供后续开发。
6. 拖拽只在按下瞬间执行 Alpha 命中；命中并开始拖拽后持续到释放，不因动画切帧中断。
7. 右键与左键共用同一 Alpha 命中规则；透明像素的右键交给底层应用。
8. 聊天继续通过桌宠右键菜单、托盘菜单等现有入口打开。
9. 自动保存成功只更新右上角绿灯和“草稿已保存”，不创建临时提示。
10. 自动保存失败显示右上角红色“保存失败”，并创建错误提示层。
11. 工作台所有操作提示均使用右上角浮动提示层，不再占据页面布局。
12. 成功和信息提示显示 3 秒；警告和错误提示显示 6 秒。
13. 鼠标悬停或键盘焦点进入提示层时暂停倒计时；提示层支持手动关闭。
14. 实时预览直接读取当前内存草稿和源素材，不依赖保存、编译或发布。
15. 运行角色和工作台预览复用 PixiJS 播放、坐标、镜像、锚点和资源释放规则。

## 3. 根因

### 3.1 透明区域阻挡鼠标

桌宠使用固定 `180×220`、透明、无边框且全局置顶的 Electron `BrowserWindow`。页面背景透明只影响绘制，不会改变 Windows 对原生窗口矩形的鼠标命中。当前代码没有调用 `BrowserWindow.setIgnoreMouseEvents()`，因此整个窗口矩形都会截获底层交互。

### 3.2 角色本体无法拖拽

`.pet-shell` 被设置为 `-webkit-app-region: drag`，但覆盖几乎整个窗口的 `.pet-open-chat` 按钮被设置为 `no-drag`。Electron 的拖拽区域是矩形，并且会忽略普通指针事件；按钮为恢复点击而排除了拖拽，最终造成角色本体不能拖、按钮外围空隙反而可以拖。

### 3.3 保存反馈重复

自动保存成功时，工作台状态同时更新为 `draftStatus: 'saved'` 并创建成功 `notice`。页面既显示右上角“草稿已保存”，又显示全宽成功横幅。

### 3.4 实时预览未接线

现有 `PreviewControls` 只维护本地 reducer。控制器状态没有传给任何图片、Canvas 或 PixiJS 渲染组件，预览区域也没有读取源素材。当前“实时预览”实际上只是控制按钮和文字占位。

## 4. 系统架构

```text
角色源图片 / 已发布纹理
          │
          ▼
共享 PixiJS 角色场景
  ├─ 当前动作与当前帧
  ├─ 帧计时、循环、镜像与缩放
  ├─ 锚点和文件挂载位置
  └─ Alpha 数据缓存
          │
          ├──────────────► 工作台 DraftCharacterPreview
          │                   ├─ 当前内存草稿
          │                   ├─ 预览控制状态
          │                   └─ 临时资源缓存
          │
          ▼
CharacterAlphaHitTester
          │
          ▼
PetInteractionController（Renderer）
  ├─ 鼠标穿透状态
  ├─ 左键拖拽手势
  └─ 右键菜单意图
          │ 固定白名单 IPC
          ▼
PetWindowInteractionController（Main）
  ├─ setIgnoreMouseEvents
  ├─ 受限拖拽会话
  ├─ CharacterMotionService 所有权切换
  └─ 工作区限制与位置保存
```

## 5. 模块设计

### 5.1 `CharacterAlphaHitTester`

命中器位于角色播放器边界，负责回答“窗口客户区中的某一点是否命中当前可见角色像素”。

职责：

- 加载纹理时提取并缓存 Alpha 字节，不在鼠标移动期间读取 GPU。
- 跟踪当前动作、当前帧、源裁切矩形和画布布局。
- 对 Pixi 缩放、`ground` 锚点、左右镜像和角色平移执行逆向坐标换算。
- 使用严格的大于判断执行 `alpha > 16`。
- 帧切换后更新命中快照。
- 资源切换和场景销毁时释放 Alpha 缓存。

命中器不得：

- 调用窗口 API。
- 执行文件操作。
- 决定拖拽、聊天或菜单行为。
- 在每次 `pointermove` 中调用 `getImageData` 或 WebGL `readPixels`。

### 5.2 `PetInteractionController`

交互控制器位于桌宠 Renderer，只消费播放器提供的命中结果。

职责：

- 根据当前光标位置和帧命中快照切换鼠标穿透状态。
- 在动画切帧且光标静止时重新判断当前位置。
- 可见像素左键按下时开始拖拽捕获。
- 拖拽期间保持窗口接收鼠标，直到释放或取消。
- 可见像素右键时请求显示现有桌宠菜单。
- 结束拖拽后重新计算鼠标穿透状态。

左键不得再调用 `openChat()`，也不得触发单击或双击扩展状态。扩展状态的数据结构、触发控制器和清单字段保留，但本次不继续开发左键扩展触发。

### 5.3 `PetWindowInteractionController`

Main 新增受限窗口交互控制器。Renderer 不获得任意 `BrowserWindow` 句柄、任意窗口选择或任意绝对位置写入能力。

固定命令：

- 更新桌宠窗口是否忽略鼠标。
- 开始当前桌宠窗口的拖拽会话。
- 结束或取消当前拖拽会话。
- 请求打开现有桌宠右键菜单。

约束：

- 只接受当前桌宠 `webContents` 发送的请求。
- 同一时间只允许一个拖拽会话。
- Main 在开始拖拽时记录系统光标和窗口原点。
- 拖拽位置由 Main 根据系统光标差值计算，Renderer 不提交任意目标坐标。
- 位置始终限制在可见显示器工作区。
- 拖拽开始时调用 `CharacterMotionService.beginUserMove()`，结束时调用对应结束逻辑。
- 窗口销毁、Renderer 销毁、应用退出、页面失焦、指针取消或超时都会终止拖拽。
- 最后一个合法位置继续通过现有位置持久化链路保存。

### 5.4 `DraftCharacterPreview`

工作台新增真正的草稿预览组件。它使用当前选中动作及其源素材，不构造虚假的已发布结果。

职责：

- 使用现有受限 `readCharacterSource` API 读取当前草稿引用的素材。
- 以“角色 ID + 素材 ID”缓存解码结果和 Blob URL。
- 将草稿动作适配到共享 PixiJS 场景。
- 响应播放、暂停、上一帧、下一帧、循环、方向、速度、背景、锚点、文件挂载和全状态巡览。
- 当前草稿修订变化时只更新受影响动作。
- 切换角色或关闭工作台时释放 Pixi 纹理、ImageBitmap、Blob URL 和 ticker。

预览不得：

- 调用保存、编译、发布或启用接口。
- 执行真实文件操作。
- 因预览失败修改已发布角色。
- 使用与运行角色不同的缩放、镜像或锚点算法。

### 5.5 `WorkshopToastLayer`

工作台通用 `notice` 改由右上角浮动提示层消费，提示层使用覆盖定位，不进入页面网格行，也不改变三栏工作区尺寸。

行为：

- 成功和信息提示显示 3 秒。
- 警告和错误提示显示 6 秒。
- 鼠标悬停或键盘焦点进入时暂停倒计时。
- 离开后从剩余时间继续，而不是重新开始完整时长。
- 支持手动关闭。
- 连续消息按到达顺序显示，避免后到消息静默覆盖尚未阅读的错误。
- 工作台关闭时清理所有计时器。

自动保存成功不进入提示队列。自动保存失败进入错误提示队列。

## 6. 详细交互流程

### 6.1 鼠标穿透

1. 播放器加载当前帧并发布命中快照。
2. Main 让窗口忽略鼠标，并使用 Electron `forward` 选项继续把鼠标移动消息送给 Chromium。
3. Renderer 收到移动消息，将窗口坐标交给命中器。
4. 透明像素保持忽略鼠标，底层窗口接收操作。
5. 可见像素请求 Main 恢复鼠标接收。
6. 当前帧变化时，即使鼠标没有移动，也使用最后光标位置重新判断。

命中数据未就绪、坐标越界或命中器异常时默认穿透，不能回退为整个窗口阻挡鼠标。

### 6.2 左键拖拽

1. 可见像素上的左键按下开始拖拽。
2. Main 记录系统光标起点与桌宠窗口起点。
3. Main 根据系统光标差值移动窗口。
4. 拖拽期间不重复执行 Alpha 判定。
5. 动画可以继续切帧，但不能导致拖拽突然结束。
6. 左键释放、取消、失焦或超时后结束拖拽。
7. 结束后保存位置并重新执行命中判断。

透明像素上的左键完全交给底层应用。

### 6.3 右键菜单

1. 可见像素上的右键请求 Main 打开现有桌宠菜单。
2. 菜单继续包含打开聊天、角色工作室、角色切换、设置、显示或隐藏桌宠和退出。
3. 透明像素上的右键穿透给底层文件、桌面或应用。

### 6.4 实时预览

1. 用户选择状态和动作。
2. 预览组件读取该动作引用的源素材并建立当前草稿修订。
3. 素材解码完成后加载到共享 PixiJS 场景。
4. 帧顺序、持续时间、FPS、循环、方向、速度和锚点修改直接更新预览。
5. 旧修订的异步结果被取消或丢弃，不能覆盖新草稿。
6. 动作无帧、素材失败或帧矩形无效时显示局部空状态或错误，不保留上一动作画面。

## 7. 状态反馈

### 7.1 草稿状态灯

| 状态 | 显示 |
|---|---|
| `dirty` | 黄灯，“有未保存修改” |
| `saving` | 黄灯，“正在保存” |
| `saved` | 绿灯，“草稿已保存” |
| `error` | 红灯，“保存失败” |
| 未选择角色 | 中性状态，“未选择角色” |

### 7.2 临时提示层

- 创建、复制、删除、导入、导出、应用网格、编译、发布和启用等操作继续生成提示。
- 所有提示显示在工作台右上角浮动层，不占据页面布局。
- 自动保存成功不生成提示。
- 自动保存失败生成错误提示。

## 8. 错误处理

| 错误 | 行为 |
|---|---|
| Alpha 数据尚未准备 | 默认穿透，等待下一次帧或指针更新 |
| Alpha 解码失败 | 默认穿透，记录稳定错误码，不阻断聊天和菜单入口 |
| 命中坐标越界 | 视为透明，不抛出到 React |
| 拖拽会话重复 | 拒绝新会话，保留当前合法会话 |
| 拖拽异常中断 | 停止移动、结束用户运动状态、保存最后合法位置 |
| 预览素材读取失败 | 预览区显示错误和重试，不修改草稿和发布版本 |
| 预览帧矩形无效 | 禁用对应动作预览并指出具体帧 |
| 旧预览异步结果晚到 | 丢弃并释放对应临时资源 |
| 自动保存失败 | 红色状态灯与 6 秒错误提示层 |

## 9. 性能要求

- Alpha 数据只在纹理加载或资源变更时提取。
- 高频命中只执行坐标换算和 Alpha 字节索引。
- 同一源精灵图被多个帧引用时只解码一次。
- 鼠标静止时不持续轮询；仅在帧变化且命中快照发生变化时重新判断。
- 预览只重建受影响动作，不重载全部角色。
- 页面隐藏或系统开启“减少动态效果”时暂停连续播放。
- 逐帧预览在减少动态效果模式下仍可使用。
- 工作台关闭后不得保留预览 ticker、Blob URL、ImageBitmap 或纹理。

## 10. 安全边界

- 所有窗口交互 IPC 使用固定通道和严格输入 Schema。
- Main 校验发送方必须是当前桌宠窗口。
- Renderer 不能选择其他窗口、读取原生句柄或发送任意绝对位置。
- 右键菜单仍由 Main 构建，Renderer 不能注入菜单命令。
- 预览只读取当前角色工作区中已授权的源素材标识。
- 预览不接收任意本地路径，不执行脚本、HTML、动态模块或真实文件任务。
- 命中检测失败以穿透为安全降级，避免透明置顶窗口持续阻塞用户桌面。

## 11. 测试策略

### 11.1 单元测试

- Alpha 为 `0` 和 `16` 时不命中，`17` 及以上时命中。
- 覆盖源裁切、缩放、锚点、左右镜像、透明空洞和越界坐标。
- 帧切换后使用最后光标位置重新判定。
- 命中数据未就绪和异常时默认穿透。
- 左键只有可见像素可以开始拖拽。
- 拖拽期间帧变透明不会中断。
- 左键不调用 `openChat`，不触发单击或双击扩展状态。
- 右键只有可见像素请求菜单。
- 非桌宠发送方的窗口交互 IPC 被拒绝。
- 拖拽取消、超时、窗口销毁和应用退出均清理会话。
- 预览状态变化产生实际播放器调用。
- 旧草稿修订不能覆盖新预览。
- 资源切换和卸载释放纹理、Blob URL 与 ticker。
- 自动保存成功不生成提示，失败生成错误提示。
- 提示层覆盖计时、悬停暂停、焦点暂停、继续计时、手动关闭和消息队列。

### 11.2 集成测试

- Pixi 当前帧、Alpha 缓存和 Renderer 交互控制器形成完整命中链路。
- Main 鼠标穿透命令只作用于桌宠窗口。
- 拖拽与 `CharacterMotionService` 自动漫游不会争用位置。
- 工作台读取真实源素材后可以预览当前草稿动作。
- 编辑帧率、顺序、方向和锚点后无需保存或发布即可刷新预览。
- 预览失败不改变角色草稿字节、发布清单和活动角色。

### 11.3 Electron E2E 与人工验收

1. 将桌宠放在测试文件或测试窗口上方。
2. 在角色透明像素处选择、双击和右键操作底层内容。
3. 在角色可见像素处左键拖动，确认释放后位置正确保存。
4. 在角色可见像素处右键打开菜单，并从菜单打开聊天。
5. 验证透明光晕和角色内部透明空洞不会阻挡底层操作。
6. 连续拖动和自动漫游不会互相抢占窗口位置。
7. 工作台编辑帧率、顺序、镜像、锚点和文件挂载时立即看到变化。
8. 验证成功、信息、警告和错误提示的右上角浮层与自动消失规则。
9. 启用“减少动态效果”后连续播放暂停，逐帧控制仍可用。
10. 观察五分钟空闲与播放状态，确认没有持续 GPU 回读或明显 CPU 异常。

## 13. 非目标

- 本次不恢复左键单击或双击扩展状态触发。
