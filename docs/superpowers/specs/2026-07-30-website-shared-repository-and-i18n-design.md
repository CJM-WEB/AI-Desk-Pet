# AI Pet 共享仓库与全站中英文切换设计

## 1. 目标

本次扩展包含两个相互关联的功能：

1. 在“下载”和“反馈与建议”之间增加“AI Pet 共享仓库”章节，让用户在本地原型中上传、浏览、点赞和下载 AI Pet 压缩包。
2. 为全站建立可扩展的国际化基础，首期支持简体中文和英文，并为后续新增语言预留统一入口。

本次实现必须严格延续现有网站的视觉语言和交互风格，不为新章节创建独立的设计体系。

## 2. 范围

### 2.1 本期包含

- 新增“AI Pet 共享仓库”章节。
- 将章节顺序调整为：
  - 首页
  - 关于
  - 下载
  - AI Pet 共享仓库
  - 反馈与建议
  - 捐款
- 复用现有章节背景、切换动画、指针视差、标题倾斜、按钮和弹窗风格。
- 使用 IndexedDB 保存本机上传的封面、ZIP 文件和投稿信息。
- 支持分页浏览、投稿、详情查看、本地点赞和本地下载。
- 建立集中式中英文语言资源。
- 在固定导航层顶部正中央提供 `language` 入口。
- 保存用户的语言选择。

### 2.2 本期不包含

- 跨设备或跨用户共享。
- 云端数据库、对象存储和上传接口。
- 用户注册、登录和身份认证。
- 投稿审核、举报、删除、编辑或版本管理。
- 自动翻译用户投稿的名称、描述和反馈内容。
- `.rar`、`.7z` 或其他非 ZIP 压缩格式。

## 3. 方案选择

### 3.1 本地数据方案

可选方案包括静态演示数据、浏览器本地原型和立即建设云端后端。本期采用浏览器本地原型：

- 相比静态演示，本地原型能完整验证上传、分页、点赞和下载流程。
- 相比立即建设云端后端，本地原型不依赖尚未确定的服务器、数据库、对象存储和账号体系。
- 页面通过仓库接口访问数据，未来接入云端时替换仓库实现，不重写主要界面。

`localStorage` 不用于保存压缩包或封面。二进制内容必须保存在 IndexedDB 中，`localStorage` 只用于保存语言选择等小型偏好数据。

### 3.2 未来云端方案

正式上线后采用对象存储方案：

- 网站后端负责身份、投稿元数据、分页、点赞、审核状态和下载权限。
- 数据库保存名称、描述、对象地址、统计数据和状态。
- 对象存储保存 ZIP 文件和封面。
- 浏览器通过后端签发的临时凭证直接上传对象存储。
- 下载前由后端校验状态，并返回短期有效的下载地址。

不将用户文件长期保存在应用服务器磁盘，也不将大体积二进制文件直接写入业务数据库。

## 4. 页面结构

### 4.1 章节接入

共享仓库接入现有章节注册和导航系统。新增章节后，所有依赖章节索引、章节 ID、章节范围和过渡顺序的映射必须同步调整，避免下载、反馈和捐款章节定位错位。

共享仓库背景直接复用现有章节的背景渲染机制，不新增与全站不一致的背景样式。

### 4.2 仓库主界面

主界面围绕中央标题组织：

- 中央显示标题“AI Pet 共享仓库”。
- 标题使用现有指针倾斜文本效果，朝鼠标方向轻微倾斜。
- 标题上方显示“分享您的 AI Pet”按钮。
- 标题下方显示 `当前页/总页数`。
- 标题左右分别显示上一页和下一页图标按钮。
- 每页最多显示 8 个分享包。

桌面端采用围绕中央内容的稳定分布，保留参考图中纸张散落的视觉感，但卡片位置必须具有明确边界，不能遮挡标题、分页和按钮。

小屏幕采用规则网格或列表排列，中央标题区域保持独立，不强行复刻桌面端的散落布局。卡片尺寸使用稳定的响应式约束，避免内容变化引起布局跳动。

### 4.3 分享包卡片

每张卡片包含：

- 封面图片。
- 分享包名称。
- 点赞图标和当前点赞数。
- 下载图标和当前下载次数。

卡片延续现有文件、纸张、边框和轻微旋转的视觉语言。点赞和下载使用项目已有图标库，不手绘新的功能图标。图标按钮具有悬浮提示和键盘焦点状态。

点击卡片主体打开详情弹窗。点击点赞或下载按钮时阻止卡片点击事件，避免同时打开详情弹窗。

### 4.4 详情弹窗

详情弹窗复用现有投稿弹窗的外观、遮罩、边框、排版和关闭方式，显示：

- 完整封面。
- 分享包名称。
- 创作者描述。
- 文件名。
- 文件大小。
- 上传时间。
- 点赞数。
- 下载次数。
- 下载操作。

本地原型没有用户账号，因此不展示虚构的创作者身份。

## 5. 投稿流程

点击“分享您的 AI Pet”打开编辑弹窗。表单字段包括：

- AI Pet ZIP 文件。
- 分享包名称。
- 创作者描述。
- 封面图片。

提交前执行以下限制：

| 字段 | 规则 |
| --- | --- |
| AI Pet 包 | 仅允许 `.zip`，最大 100 MB |
| 封面 | 允许 `.png`、`.jpg`、`.jpeg`、`.webp`，最大 5 MB |
| 名称 | 必填，去除首尾空白后最多 30 个字符 |
| 描述 | 必填，去除首尾空白后最多 500 个字符 |

同名投稿允许存在，记录通过独立 ID 区分。表单校验失败时保留用户已经填写的其他内容，并在对应字段附近显示本地化错误信息。

上传成功后：

1. 将元数据、封面 Blob 和 ZIP Blob 原子写入 IndexedDB。
2. 关闭投稿弹窗。
3. 重新读取第一页数据。
4. 更新总页数。
5. 显示新投稿所在的第一页。

写入失败、浏览器不支持 IndexedDB 或存储空间不足时，不显示成功状态，也不清空用户已填写的表单。

## 6. 分页与动画

- 默认按创建时间从新到旧排序。
- 每页最多 8 条。
- 没有上一页或下一页时，对应按钮禁用。
- 空仓库显示本地化空状态，不显示 `1/0`；页码区域显示 `0/0`。
- 上传第一条记录后页码变为 `1/1`。

切换页面时：

1. 当前页卡片按“从上到下、从左到右”的顺序依次向左滑出。
2. 当前页全部退出后切换数据。
3. 下一页卡片按相同顺序从右向左依次滑入。
4. 动画期间锁定分页按钮，防止连续点击造成状态竞争和卡片重叠。

用户启用“减少动态效果”时，保留页面切换结果，但缩短或取消位移动画。

## 7. 点赞与下载

### 7.1 点赞

- 点赞状态保存在 IndexedDB。
- 同一浏览器对同一分享包只能保持一个点赞状态。
- 第一次点击增加 1 个点赞，再次点击取消并减少 1 个点赞。
- 点赞数不得低于 0。
- 本地原型不声称点赞来自多个真实用户。
- 未来云端版本按登录用户和投稿 ID 保存唯一点赞关系。

### 7.2 下载

- 点击下载后从 IndexedDB 读取 ZIP Blob。
- 浏览器生成临时对象地址并触发下载。
- 下载文件名优先使用用户上传时的原始文件名。
- 下载触发后及时释放临时对象地址。
- 成功触发下载后，本地下载次数增加 1。
- 文件不存在或读取失败时显示本地化错误提示，不增加下载次数。

## 8. IndexedDB 数据设计

IndexedDB 使用两个对象仓库：

- `sharedPetMetadata` 保存列表和详情所需的元数据及封面。
- `sharedPetFiles` 以相同 ID 保存 ZIP Blob。

两个对象仓库必须在同一事务中写入，避免出现只有元数据或只有文件的残缺投稿。列表和详情查询不得读取 ZIP Blob，防止一页 8 个大文件同时进入内存。

页面使用的数据类型至少包含以下字段：

```ts
interface SharedPetPackageSummary {
  id: string;
  name: string;
  description: string;
  coverFile: Blob;
  coverFileName: string;
  packageFileName: string;
  packageSize: number;
  liked: boolean;
  likeCount: number;
  downloadCount: number;
  createdAt: string;
}

interface CreateSharedPetInput {
  name: string;
  description: string;
  coverFile: File;
  packageFile: File;
}

interface SharedPetPage {
  items: SharedPetPackageSummary[];
  page: number;
  pageSize: 8;
  totalItems: number;
  totalPages: number;
}

interface SharedPetDownload {
  file: Blob;
  fileName: string;
}
```

仓库层向页面提供稳定接口：

```ts
interface SharedPetRepository {
  listPage(page: number, pageSize: 8): Promise<SharedPetPage>;
  create(input: CreateSharedPetInput): Promise<SharedPetPackageSummary>;
  getById(id: string): Promise<SharedPetPackageSummary | null>;
  toggleLike(id: string): Promise<SharedPetPackageSummary>;
  getDownload(id: string): Promise<SharedPetDownload>;
  recordDownload(id: string): Promise<SharedPetPackageSummary>;
}
```

页面不得直接调用 IndexedDB。数据库初始化、事务、异常归一化和 Blob 读取均由仓库实现负责。

封面展示使用临时对象地址。组件卸载、数据刷新或封面替换时必须释放旧地址，避免长期浏览造成内存泄漏。

## 9. 国际化设计

### 9.1 语言规则

- 首次访问时读取浏览器语言。
- 中文环境默认使用简体中文。
- 其他语言环境默认使用英文。
- 用户手动选择后，将语言代码保存到本地偏好存储。
- 后续访问优先使用用户选择，不再覆盖为浏览器语言。
- 首期语言代码为 `zh-CN` 和 `en`。

### 9.2 语言入口

- `language` 按钮位于固定导航层顶部正中央。
- 用户位于任意章节时都可以打开语言菜单。
- 首期菜单包含“简体中文”和“English”。
- 当前语言具有明确选中状态。
- 菜单结构允许后续直接增加语言项。
- 切换语言时当前章节原位更新，不跳转回首页，也不重新触发章节入场动画。

### 9.3 文案组织

语言资源按功能域拆分：

- 全局与导航。
- 首页。
- 关于。
- 下载。
- AI Pet 共享仓库。
- 反馈与建议。
- 捐款。
- 表单校验与错误提示。

组件通过稳定文本键读取文案，不在组件中零散编写语言判断。所有网站自带的可见文本都必须纳入语言资源，包括标题、按钮、说明、弹窗、表单标签、占位文字、校验提示、空状态和错误状态。

用户输入的分享包名称、描述和反馈投稿内容保持原语言，不自动翻译。`AI Pet`、`PayPal` 等产品或品牌名称保持原名，只翻译周边说明。

建议英文文案保持简短，例如：

| 简体中文 | 英文 |
| --- | --- |
| 分享您的 AI Pet | Share Your AI Pet |
| AI Pet 共享仓库 | AI Pet Community |
| 反馈与建议 | Feedback & Ideas |
| 立即下载 | Download |

切换语言时同步更新页面根元素的 `lang` 属性为 `zh-CN` 或 `en`。

## 10. 风格一致性约束

- 复用现有字体、颜色、边框、阴影、背景、按钮和弹窗变量。
- 复用现有章节切换、指针倾斜和悬浮反馈实现。
- 不引入新的主色体系、渐变装饰或独立卡片设计语言。
- 不创建卡片嵌套卡片。
- 英文文案不得通过随视口无限缩小字体解决溢出，应使用简短翻译、稳定尺寸和合理换行。
- 所有固定格式元素必须设置明确尺寸或响应式约束。
- 动态文本、页码、错误信息和按钮不得互相遮挡。
- 功能按钮优先使用图标，陌生图标提供悬浮说明。

## 11. 错误处理

页面需要区分并本地化以下错误：

- IndexedDB 不可用。
- 数据库初始化失败。
- 存储空间不足。
- ZIP 格式或大小不符合要求。
- 封面格式或大小不符合要求。
- 名称或描述为空、超长。
- 分享包不存在。
- 文件读取失败。
- 下载触发失败。

仓库层返回可识别的错误类型，页面负责把错误类型映射为当前语言的用户文案。不得直接向用户展示浏览器原始异常文本。

## 12. 测试与交付

实现阶段至少覆盖：

- 章节注册和新顺序。
- 浏览器语言识别、用户选择持久化和回退规则。
- 中英文资源键完整性。
- 上传字段校验边界。
- IndexedDB 新建、分页、详情读取、点赞切换和下载计数。
- 每页固定 8 条及空状态页码。
- 分页动画状态锁。
- 对象地址释放。
- 现有章节在新增索引后的导航行为。
- 类型检查、单元测试和生产构建。

Codex 完成实现后只执行必要的自动化测试、类型检查和构建检查，不逐页打开网站进行人工视觉验收。最终视觉与交互验收由用户在本地网站中完成。

## 13. 未来云端安全要求

本地原型不实现云端安全流程，但未来接口必须预留以下边界：

- 账号登录和上传频率限制。
- 服务端文件扩展名、MIME 和文件签名校验。
- ZIP 路径穿越和压缩炸弹防护。
- 恶意文件扫描和隔离区。
- 封面与描述内容审核。
- 投稿审核状态。
- 举报、下架和删除机制。
- 版权声明和使用条款。
- 对象存储私有权限及短期签名下载地址。

在上述能力完成前，不将本地原型描述为可安全公开的匿名上传平台。

## 14. 完成标准

- 新章节位于“下载”和“反馈与建议”之间。
- 每页最多展示 8 个分享包，分页和顺序动画符合设计。
- 用户能在同一浏览器内完成上传、查看、点赞、取消点赞和下载。
- 文件与封面遵守已确认的格式和大小限制。
- 刷新页面后本地投稿和语言选择仍然存在。
- 全站网站自带文案可在简体中文和英文之间切换。
- 用户投稿内容保持原文。
- 新章节与现有网站在视觉、动效和交互上保持统一。
- 未引入云端服务依赖，也未虚构跨用户共享能力。
