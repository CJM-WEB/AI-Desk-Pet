# 网站 E2E 职责减法设计

> 文档状态：用户已于 2026-08-20 二次批准大量删除范围；第 9 节 trace 截图减法已验证失败并撤销
> 日期：2026-08-20
> 适用范围：网站 Playwright 验收、网站组件/控制器测试、网站验证文档

## 1. 背景与问题

当前 `tests/e2e/website.spec.ts` 包含 44 项测试和约 2462 行代码，在同一 Playwright worker 中同时承担 helper、内存 API、领域规则、组件状态、视觉截图、布局扫描、GPU 动画和真实业务流程。浏览器上下文虽然按测试隔离，但 Chromium/GPU 进程仍由 worker 复用。

2026-08-20 使用唯一正式入口 `pnpm test:e2e:website` 重新运行当前 44 项：前 10 项通过，第 11 项 `介绍章节桌面悬停与键盘聚焦同步玻璃交互` 约 1.1 分钟失败。该行为已经由 `about-model.test.ts` 与 `about-chapter.test.tsx` 覆盖。此前增加 worker、独立浏览器 fixture、WebGL cleanup 和逐项 CLI 均未形成稳定完整门，相关实现已经删除。

继续增加隔离、超时或重试不能解决职责堆叠。本设计把 E2E 收回到只有真实浏览器才能证明的业务接缝，并删除重复证据。

## 2. 目标与非目标

### 2.1 目标

1. 将网站 E2E 从 44 项减少到 16 项，只保留真实页面、地址栏、浏览器输入冒泡、CSS 断点、真实图片加载与 WebGL 接缝。
2. 将 4 项组件或控制器状态迁入现有测试文件，不新增测试文件。
3. 删除 24 项已由更低层测试覆盖、纯 helper/API 或无像素基线的自动截图/布局任务。
4. 将不能由自动断言可靠证明的视觉检查记录到既有人工验收文档。
5. 保持原生 Playwright 唯一入口和现有串行、单 worker、零重试、既有超时。

### 2.2 非目标

- 不修改网站产品组件、WebGL、动画、Repository 或业务 API。
- 不新增 runner、fixture、测试框架、依赖、重试、超时或产品分支。
- 不触碰桌面端、Agent、文件工具、角色实现或桌面测试。
- 不执行正式部署、CloudBase 资源修改或远端数据操作。
- 不为追求行数删除缺少替代证据的安全与核心业务流程。

## 5. 批准后删除的 24 项

### 5.1 helper、内存 API 与重复领域规则

1. `服务器就绪等待在成功、超时和取消路径统一清理资源`
2. `五章节按确认顺序注册且各章节具有明确状态`
3. `内存 API 复用公开信封且投稿不会绕过管理员审核`
4. `自动驳回只能转人工且技术扫描失败始终禁止批准`
5. `已发布内容删除后立即隐藏并在三天隔离区恢复后重新出现`
6. `管理员写操作校验版本、理由和幂等键并拒绝错误 Bearer`
7. `介绍章节桌面悬停与键盘聚焦同步玻璃交互`
8. `反馈章节展示排序列表、远端只读状态与建议滚筒`
9. `下载平台选择器切换平台并保留当前章节`
10. `下载章节公开安装与常见问题文本，并准确展示 Windows 发布状态`
11. `窗口 blur 和 focus 会同步下载与支持章节暂停状态`
12. `matchMedia 初始化异常时进入静态回退且不出现黑屏`
13. `WebGL 上下文不可用时仅首页进入静态回退`
14. `静态回退通过运行时属性关闭章节与付款码动效`
15. `PageDown 推进非纵向滚动章节并在终点保留共享液态背景`
16. `下载与支持章节主要控件保持可操作且不残留旧外围文件层`

这些职责分别由现有 website 组件/模型测试、CloudBase 服务测试、管理员客户端测试或保留的完整真实页面流程覆盖。删除 E2E 不删除底层安全测试。

### 5.2 视觉、布局与无基线截图任务

17. `568x320 介绍章节五项内容可读且键盘焦点可切换`
18. `逐章节透明交接保持原位层级并生成截图证据`
19. `支持页左右按钮组呈现 0/2.5/5 景深且后层按钮先切换再执行业务`
20. `支持章节不显示黄色 Canvas 光场并保留两组核心操作`
21. `目标视口五章节无溢出遮挡且减少动态效果保持完整导航`
22. `568x320 窄横屏支持章节滚筒保持在视口内且页面无横向溢出`
23. `移动下载操作按钮避让章节导航`
24. `390 首屏直接交互且点击下一章节一次进入介绍章`

其中第 21 项单独设置 180 秒，执行 5 个视口 × 5 个章节的 25 次布局扫描并写出两张没有像素基线的截图，单项实际约 1.8 分钟。此类检查改为发布候选阶段人工视觉验收；移动断点与关键遮挡关系仍由保留的 4 项布局 E2E 覆盖。

## 6. 删除联动与单一事实来源

删除 28 个 E2E 测试块后，同时删除只服务这些测试的 helper、类型、常量、导入和截图路径。不得保留注释掉的测试、兼容别名、跳过标记或第二份清单。

预期：

- E2E `44 → 16`，减少 63.6%；
- 测试块毛减约 953 行；
- 孤儿 helper/常量毛减约 272 行；
- 下沉测试新增不超过约 100 行；
- 最终净减少约 1100 行。

## 9. Trace 截图减法修订（已证伪并撤销）

16 项 E2E 首次完整运行在前 5 项通过后，第 6 项 `普通滚轮连续追赶、吸附、隔离惯性并重计新手势` 于第一步 `mouse.move` 耗尽 60 秒总预算。失败 trace 显示该次 `mouse.move` 自身约耗时 21.5 秒，并在一个失败用例内保存了 83 张 JPEG。业务断言尚未开始，不能把失败归因于滚轮状态机。

当前 `trace: 'retain-on-failure'` 会在测试执行期间持续预录页面截图，成功后才丢弃；网站首页 WebGL 在五个章节间持续工作，截图会触发 GPU 画面读回。仓库锁定的 Playwright 1.61.1 类型支持在保留 trace 的同时独立关闭 `screenshots`。

获批验证曾把 `tests/playwright.website.config.ts` 的 trace 配置替换为：

```ts
trace: {
  mode: 'retain-on-failure',
  screenshots: false,
  snapshots: true,
  sources: true
}
```

该配置把失败 trace 的页面图片从 83 张降为 1 个非连续截图附件，证明截图录制已关闭；但首 6 项锁定序列仍为 `5 passed / 1 failed`，第 6 项继续在第一步 `mouse.move` 耗尽 60 秒。因此连续截图不是充分根因，配置已恢复为原值。不得继续关闭整个 trace、增加超时或叠加测试外围；下一步必须重新审查网站 WebGL 的运行职责和生命周期。
