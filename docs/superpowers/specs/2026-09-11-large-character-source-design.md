# 本地大尺寸角色素材导入

## 授权、目标与范围

2026-09-11 用户明确要求解除本地素材导入的规格与大小限制，以便导入由 500～1000 像素单帧拼接的长序列图。本规格将该要求具体化：移除本地 PNG／WebP 源图整图 4096 像素、单文件 32 MiB、每角色源图总量 512 MiB 的产品限制；同时打通切帧、草稿预览和本地编译发布。用户本次请求为实施授权，无需重复确认相同范围。

非目标：不改变官网、CloudBase、包扫描器及共享角色压缩包的解压／导出预算；不扩展 Renderer 文件权限，不修改聊天、模型与行为仲裁，不新增依赖。不移除每动作 500 帧、单帧 4096 像素等运行契约。大源图应先切帧；不承诺任意硬件均可解码任意体积的图片。

## 现状证据

- `image-metadata.ts` 把运行图集的 4096 边长用于整个源图；Main 导入、catalog 恢复和读取均再次施加限制。
- Main 本地源图导入在整文件读取后检查 32 MiB／512 MiB，移除其中一处不能解决重开失败。
- 网格表单行列上限 64，store 仅要求正安全整数和网格容量。
- `planAtlas` 每动作仅生成一页；V2／V3 发布表现累计帧面积不能超过 4096²，17 张 1024² 帧会失败。
- 草稿预览把源图直接作为 Pixi 纹理，帧矩形不会消除整图 GPU 边长限制。
- 正式播放器已经按每帧 `assetId` 选纹理，现有资源数组与多 SHA 几何修订可直接表达分页。

## 方案与链路

1. 图片元数据解析显式区分本地源图与运行资源；默认严格运行资源策略保持。源图保留格式签名、结构、CRC、正尺寸和格式自身数值边界，不设额外宽高或字节上限。Main 的路径身份、非链接、SHA、事务、读取一致性校验保持。
2. 移除本地源图 catalog、导入与总存储的人为大小检查；不通过修改共用常量间接放宽其他资源边界。移除网格行列的 64 表单上限，保留正整数和 500 帧限制。
3. 复用确定性 shelf 布局，将原单图集规划改为分页。每页最多 4096×4096，不缩放帧、不改变顺序、时长或锚点；单帧放不下仍明确失败。
4. 编译器返回 `pages[{assetId,mimeType,bytes,width,height}]`、全量 `frames`、源校验和与统一几何。逐页绘制、扫描和释放画布；复用现有几何 accumulator，避免同时复制全部帧 alpha。同一源对象不重复计算 SHA。
5. store 按每页 SHA 去重，映射每帧资源引用；几何修订为使用到的去重 SHA 排序后连接。所有页随同一次现有事务发布，失败不发布部分结果。
6. 正式表现不再以累计面积约束所有帧到单页；保留数量和单帧边长，并验证矩形不越过图集最大边界。编译器根据真实解码尺寸验证源矩形、计算几何。Main 继续检查清单引用、文件集合、长度与 SHA；当前合法 V3 发布并不重新解码核对页尺寸或重算几何，不能把这一既有缺口写成已验证边界，本次不扩展发布安全模型。
7. 草稿预览在上传纹理之前裁切／分页大源图，重映射预览帧但保持编辑帧身份与原始源矩形。复用现有加载取消、迟到结果失效和资源释放机制。小素材继续正常预览。

## 失败、资源与迁移

浏览器／Electron 解码器、Canvas、连续 Buffer、显存、可用内存和磁盘仍是实际边界。解码或导出失败必须返回失败，不伪造成功，不自动降低分辨率。分页限制单张临时画布大小，但当前仍完整解码源图、加载动作资源，未引入流式解码或承诺恒定内存。

编译器自身支持 AbortSignal，工作室保留现有修订失效后丢弃结果的逻辑，未新增在修改草稿时立即中断底层编译的承诺。

无需用户数据迁移；旧小素材和单页表现继续有效。替换单页专属编译路径及旧大小拒绝测试，不保留第二套正式编译器。本规格仅覆盖旧角色工作室规格中的本地源图大小预算和单表现单图集面积限制，其他安全／角色契约继续适用。

## 验证

- RED → GREEN：超过 4096 的源图导入、重新读取与重建服务；超过 32 MiB 的合法源图；源目录超过旧总量仍能导入；损坏结构、越界路径等继续拒绝。
- 布局：16／17 张 1024²、64／65 张 512² 分页，顺序、边界、无重叠及非法输入。
- 编译与 store：跨页资源、摘要去重、统一几何、第二页失败／取消清理、一次完整发布。
- Schema：多页表现通过，单帧超限／越界矩形继续失败，重复裁片合法。
- 预览：长图不会整图上传，裁片、帧身份、取消和 URL／纹理释放正确；大列数网格不被表单拦截。
- 定向测试、相关包 typecheck、全仓 typecheck、`verify:characters`／`verify:desktop`，保留真实失败事实并补跑被提前失败阻断的相关门禁。
- 使用实际浏览器／Electron 图像解码和 Canvas 验证长序列编译；原生桌面实际观感与大规模设备容量仍待用户人工确认。验收独立记录，不把计划当作通过证明。
