# AI 桌宠文件夹空间与资源管理器图层设计

> 文档状态：已确认设计  
> 产品名称：`AI Pet`
> 目标平台：Windows 10/11  
> 基准日期：2026-07-27

## 1. 目标

让桌宠具有可持续的“空间位置”。桌宠进入文件夹后从桌面消失，只在该文件夹对应的资源管理器内容区域出现并活动；用户可从托盘呼唤或召回桌宠。

## 2. 已确认行为

1. 桌宠位置分为桌面和文件夹，不再只是屏幕坐标。
2. 进入文件夹后，桌面角色窗口隐藏。
3. 目标文件夹打开时，桌宠显示在其资源管理器内容区域。
4. 活动和文件交互范围仅限当前文件夹。
5. 文件夹关闭后，桌宠仍停留其中但不可见。
6. 托盘“呼唤桌宠”打开其所在文件夹并显示桌宠。
7. 托盘“召回桌面”将桌宠位置改回桌面。
8. 同一路径在多个窗口或标签页打开时，只绑定最近激活的实例，不产生分身。
9. 文件夹重命名或同卷移动后尽量继续追踪。
10. 位置不可访问时进入失联状态；删除、磁盘拔出或长期不可访问时可召回桌面。

## 3. 技术边界

不向 `explorer.exe` 注入代码，也不修改资源管理器进程。采用独立 Windows 辅助进程：

- Windows UI Automation 识别资源管理器窗口、标签页、当前路径和文件内容区域。
- WinEvent Hook 监听窗口激活、移动、缩放、最小化和销毁，避免高频轮询。
- Win32 窗口 API 将 Electron 透明角色窗口绑定到目标资源管理器的层级附近。
- Electron 继续负责角色渲染、命中区域、状态和业务 IPC。

辅助进程通过带版本的 JSON Lines 协议与 Electron Main 通信，只暴露窗口观察、目录标识和图层定位能力，不提供任意系统命令。

## 4. 空间模型

```ts
type PetHabitat =
  | { kind: 'desktop'; displayId: string; position: { x: number; y: number } }
  | {
      kind: 'folder';
      folderIdentity: {
        volumeId?: string;
        fileId?: string;
        canonicalPathHint: string;
      };
      localPosition: { x: number; y: number };
      availability: 'hidden' | 'visible' | 'disconnected';
    };
```

本地持久化可以保存真实路径，但 Renderer 和普通日志只接收脱敏路径提示。NTFS 本地目录优先使用卷标识和文件标识追踪；网络目录或无法取得文件标识的目录使用规范化路径回退。

## 5. 图层与可见性

- 桌面栖息地沿用桌面透明窗口。
- 文件夹栖息地使用非全局置顶的透明覆盖窗口。
- 覆盖窗口边界严格跟随资源管理器文件内容区域，不覆盖地址栏、工具栏和侧边栏。
- 资源管理器失焦或被其他窗口遮挡时，桌宠不能越过遮挡窗口显示。
- 资源管理器最小化、关闭、切换到其他标签页或离开目标路径时隐藏桌宠。
- 重新激活同一文件夹时恢复局部位置。
- 透明区域点击穿透；只有角色命中区域接收点击和拖动。

## 6. 文件夹进入、呼唤与恢复

进入文件夹是一个受控状态迁移：

1. 权限层确认目标文件夹允许访问。
2. 角色播放进入动画；动画只提供表现。
3. Main 持久化文件夹身份和局部位置。
4. 隐藏桌面实例。
5. 若目标窗口已打开则绑定，否则保持不可见。

“呼唤桌宠”：

1. 查询持久化位置。
2. 若位于桌面，显示并聚焦桌宠。
3. 若位于可访问文件夹，使用系统方式打开该目录。
4. 等待 UI Automation 识别目标窗口或标签页后绑定。
5. 超时则提示失败原因，并提供“召回桌面”。

位置失效：

- 临时断线不立即清除位置。
- 本地目录被删除或身份无法匹配时标记失联。
- 用户呼唤时若仍不可访问，明确提示并允许召回。
- 不自动在相似名称目录中猜测桌宠位置。

## 7. 多窗口规则

同一文件夹存在多个候选窗口或标签页时：

- 选择最近由用户激活的候选。
- 切换候选时先隐藏旧覆盖窗口，再绑定新目标。
- 任意时刻只允许一个可见桌宠渲染实例。
- 窗口事件乱序时以递增事件序号和当前前台窗口复核结果为准。

## 8. 性能与容错

- 常态使用事件监听，不持续截图、不持续扫描文件系统。
- 窗口拖动期间合并边界更新，渲染刷新与 UI Automation 查询解耦。
- 辅助进程崩溃时隐藏文件夹覆盖窗口，不影响聊天和 Agent。
- Electron Main 负责重启辅助进程并限制重启频率。
- 睡眠、显示器变化、Explorer 重启后重新发现目标，不复用过期 HWND。

## 9. 验收标准

1. 进入文件夹后桌面桌宠消失，目标文件夹打开后只出现一个桌宠。
2. 桌宠不会覆盖资源管理器工具栏，也不会始终浮在其他应用之上。
3. 切换窗口、标签页、最小化和关闭时可见性正确。
4. 同一路径多窗口时只绑定最近激活实例。
5. 托盘“呼唤桌宠”能打开目标文件夹并完成绑定。
6. 托盘“召回桌面”在目录不可访问时仍可工作。
7. 文件夹同卷重命名或移动后能够继续追踪。
8. 磁盘断开、Explorer 重启和辅助进程崩溃不会产生残留置顶窗口。
9. 空闲状态不使用高频轮询，后台 CPU 和内存满足产品性能预算。
