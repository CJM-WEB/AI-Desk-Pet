# AI Pet 官网剩余模块视觉与交互设计

> 日期：2026-07-26
>
> 状态：设计已确认，等待书面规格审阅

## 1. 设计目标

在现有沉浸式首页基础上完成官网的多章节视觉框架，并优先实现“AI Pet 下载安装”和“捐款”两个正式模块。

整站不采用传统纵向页面滚动。滚轮、触屏手势和键盘输入驱动相邻模块进行连续的缩放与渐隐交接，形成前一模块被推远、后一模块从屏幕外推进视野的镜头感。

本轮必须保留并接入以下五个章节：

1. 首页
2. AI Pet 介绍占位
3. AI Pet 下载安装
4. 用户反馈与建议箱占位
5. 捐款

两个占位章节必须参与完整的进入、停留和退出流程，不能从章节序列中跳过。

## 2. 本轮范围

### 2.1 包含内容

- 将现有首页进度控制器扩展为五章节连续进度系统。
- 保留现有首页开场、文件粒子、文件预览和鼠标光场。
- 实现可配置的平台下载卡片滚筒。
- 实现常见问题与安装前须知的左右侧移交互。
- 实现两个可见且可替换的占位章节。
- 实现可配置的支付方式滚筒与付款码弹层。
- 复用首页文件粒子和鼠标光场，并为捐款章节提供黄色主题。
- 提供桌面完整体验和移动端可用降级。
- 覆盖键盘、触屏、减少动态效果和初始化失败路径。

### 2.2 不包含内容

- 不设计 AI Pet 介绍的正式文案与最终视觉。
- 不设计用户反馈与建议箱的正式表单、接口和提交行为。
- 不新增 macOS 安装包或虚构下载链接。
- 不接入支付接口，不处理支付结果。
- 不生成或修改微信、支付宝付款码图片。
- 不修改桌面端、Agent、文件工具或发布流程。
- 不进行部署或 Git 写操作。

## 3. 设计原则

### 3.1 延续现有首页

- 使用现有首页的浅灰背景 `rgb(235, 235, 235)` 和深色文字体系。
- 保留 Inter 与系统无衬线字体栈。
- 动画继续以 GSAP、CSS transform、opacity 和 filter 为主。
- 文件粒子、预览卡片和鼠标光场必须复用现有实现。
- 新模块保持克制、清晰和宽松，不引入与首页冲突的装饰体系。

### 3.2 配置驱动

- 章节顺序由注册表管理。
- 平台、安装说明、常见问题、支付方式和占位文案均独立配置。
- 动画组件不得根据 Windows、macOS、微信或支付宝名称编写行为分支。
- 后续新增平台或支付方式时，不修改滚筒算法。

### 3.3 输入一致性

- 滚轮、方向键、Page Up、Page Down 和触屏手势都进入统一章节控制器。
- 悬停交互必须提供键盘聚焦和点击等价操作。
- 局部滚筒获得焦点或指针进入时，可以优先消费滚轮输入。
- 页面失焦、标签页隐藏或章节离开时暂停无意义动画。

## 4. 整体架构

```text
WebsiteExperience
├─ ChapterController
│  ├─ 滚轮输入
│  ├─ 触屏手势
│  ├─ 键盘输入
│  ├─ 章节吸附
│  └─ 局部输入优先级
├─ ChapterRegistry
│  ├─ 首页
│  ├─ AI Pet 介绍占位
│  ├─ AI Pet 下载安装
│  ├─ 用户反馈与建议箱占位
│  └─ 捐款
├─ SharedVisualLayers
│  ├─ 文件粒子
│  ├─ 文件预览
│  └─ 鼠标光场
└─ ModalLayer
   └─ 付款码弹层
```

现有 `HomeExperience` 保留首页内部职责，不继续承担整站章节编排。新的 `WebsiteExperience` 负责全局输入、章节进度、层级和异常回退。

文件粒子与鼠标光场从首页专属视觉层提升为共享视觉能力，通过配置决定是否启用、颜色主题、粒子数量和中央安全区。

## 5. 章节进度模型

### 5.1 全局进度

全局进度范围为 `0–4`，整数表示章节完整停稳：

| 进度 | 章节 |
| --- | --- |
| `0` | 首页 |
| `1` | AI Pet 介绍占位 |
| `2` | AI Pet 下载安装 |
| `3` | 用户反馈与建议箱占位 |
| `4` | 捐款 |

小数表示相邻章节交接。例如 `1.35` 表示 AI Pet 介绍正在退出，AI Pet 下载安装正在进入。

### 5.2 局部进度

每次只让当前章节和相邻章节参与可见渲染。控制器从全局进度派生：

- 当前章节索引。
- 相邻章节索引。
- 交接方向。
- `0–1` 的局部交接进度。
- 当前稳定章节。
- 是否允许章节内部交互。

### 5.3 推拉镜头

前一章节退出：

- 比例从 `1` 缩小到约 `0.58`。
- 透明度从 `1` 降到 `0`。
- 适度降低对比度并增加模糊。
- 交接开始后关闭内部指针事件。

后一章节进入：

- 比例从约 `1.32` 缩小到 `1`。
- 透明度从 `0` 增加到 `1`。
- 模糊和亮度恢复到稳定状态。
- 只有完整停稳后开放内部交互。

两个章节在交接中段短暂重叠，通过层级、模糊和亮度保持空间前后关系。反向滚动使用同一组数学关系反演，不维护第二套动画。

### 5.4 吸附与边界

- 输入停止后吸附到最近整数章节。
- 一次快速滚动最多推进一个章节。
- 章节 `0` 和章节 `4` 为硬边界。
- 吸附动画约为 `240–360ms`，使用缓出曲线。
- 连续输入期间动画直接映射进度，不叠加额外缓动。

## 6. 首页接入

- 保留现有 AP 磁吸开场、完整 Logo、文件粒子和鼠标跟随。
- 开场结束后首页对应全局进度 `0`。
- 首页当前退场进度改由全局章节控制器提供。
- 首页退场时品牌、文件粒子和光场继续保持分层缩小。
- 首页开场阶段的滚轮或点击仍可跳过开场，但不能同时越过首页章节。

## 7. AI Pet 介绍占位

- 完整注册为章节 `1`。
- 中央显示“AI Pet 介绍”。
- 辅助状态显示“内容准备中”。
- 不出现正式介绍、功能列表或操作按钮。
- 背景使用浅灰基底和低透明度、低频率的轻量轨迹效果。
- 不捕获章节滚轮输入。
- 辅助技术读取“AI Pet 介绍，内容准备中”。

后续正式模块只替换章节组件，不修改章节顺序、进度模型或输入控制器。

## 8. AI Pet 下载安装

### 8.1 背景

- 中央沿用首页浅灰背景。
- 左右两侧使用 `rgb(0, 255, 200)` 青蓝色。
- 两侧颜色向中央自然渐变，不形成生硬色块边界。
- 左右箭头指向页面中心，并进行小幅、低频水平简谐运动。
- 箭头同时是可点击、可聚焦的面板控制按钮。

### 8.2 平台数据

每个平台配置至少包含：

```ts
interface DownloadPlatform {
  id: string;
  name: string;
  status: 'available' | 'coming-soon';
  summary: string;
  versionLabel: string;
  systemRequirements: string;
  downloadUrl?: string;
}
```

Windows 平台通过适配器读取现有 `release-manifest.json`，保留真实版本、文件大小、文件名、SHA-256 和下载地址。

macOS 平台状态为 `coming-soon`：

- 可以切换到最上层。
- 可以展示系统说明。
- 明确显示“即将支持”。
- 不提供下载行为。
- 不配置临时或虚构链接。

### 8.3 平台卡片滚筒

- 当前平台卡片位于中央、尺寸最大、层级最高。
- 其他平台卡片在上下方露出一部分。
- 点击露出的卡片边缘可将其切换到最上层。
- 指针位于卡片区域时，滚轮优先切换平台。
- 卡片获得焦点时，方向键优先切换平台。
- 指针移出或焦点离开后恢复章节输入。
- 触屏端支持点击和垂直拖动切换。
- 卡片位置根据循环索引距离计算，不依赖固定数量。

### 8.4 左右信息面板

左侧为“常见问题”，右侧为“安装前须知”。

右侧触发时：

- 中央平台滚筒向左移动视口宽度的约 `12–16%`。
- 右侧信息区从右侧进入。
- 内容按从上到下、从右向左的方向错峰渐显。

左侧触发时：

- 中央平台滚筒向右移动相同距离。
- 左侧信息区从左侧进入。
- 内容按从上到下、从左向右的方向错峰渐显。

面板状态规则：

- 悬停或聚焦提供临时展开。
- 点击箭头后锁定展开。
- 再次点击当前箭头、点击中央平台滚筒或按 `Esc` 还原。
- 左右面板互斥。
- 从一侧切换到另一侧时，先收回当前侧，再展开目标侧。

内容以数组配置，优先复用现有安装帮助与 FAQ 文案，后续可以直接替换。

### 8.5 移动端

- 不执行整页横向偏移。
- 左右箭头改为明确的触屏控制。
- 信息面板在中央卡片下方以抽屉形式展开。
- 平台卡片、信息抽屉和文字不得产生横向滚动。

## 9. 用户反馈与建议箱占位

- 完整注册为章节 `3`。
- 中央显示“用户反馈与建议箱”。
- 辅助状态显示“内容准备中”。
- 不出现不可用输入框、提交按钮或虚构反馈流程。
- 背景使用与 AI Pet 介绍占位一致的克制动态骨架，并通过配置区分名称和轻量轨迹参数。
- 不捕获章节滚轮输入。
- 辅助技术读取“用户反馈与建议箱，内容准备中”。

## 10. 捐款

### 10.1 标题

显示固定文案：

> 助力开发，你便也是我不可或缺的参与者

- 颜色使用 `rgb(90, 90, 90)`。
- 桌面端使用较大的固定字号档位。
- 移动端通过断点切换字号，不使用随视口宽度无限缩放的字体。

### 10.2 共享背景

- 复用首页文件粒子、文件预览和鼠标光场。
- 鼠标光场颜色改为 `rgb(255, 255, 0)`。
- 文件仍可悬停、键盘聚焦并查看预览。
- 支付卡片中央区域配置为粒子安全区。
- 捐款章节未激活时暂停粒子动画和事件监听。
- 降低移动端粒子数量和模糊成本。

### 10.3 支付方式数据

每个支付方式配置至少包含：

```ts
interface PaymentMethod {
  id: string;
  name: string;
  qrImagePath: string;
  imageAlt: string;
}
```

当前配置微信和支付宝。支付方式列表可以继续扩展，滚筒组件不得依赖固定数量。

### 10.4 支付方式滚筒

- 当前支付方式位于页面中央、尺寸最大、层级最高。
- 其他支付方式位于上下两侧，略小并被当前卡片遮挡约一半。
- 滚轮、方向键、触屏拖动或点击露出区域可切换当前项。
- 点击非当前卡片只执行切换。
- 点击当前卡片打开对应付款码。
- 位置、比例、透明度和层级根据与当前索引的循环距离计算。

### 10.5 输入优先级

- 指针位于支付滚筒区域时，滚轮只切换支付方式。
- 支付滚筒拥有键盘焦点时，方向键只切换支付方式。
- 指针移出或焦点离开后恢复章节切换。
- `Esc` 退出局部交互状态或关闭付款码弹层。

### 10.6 付款码弹层

- 弹层覆盖当前章节。
- 背景降低清晰度和亮度。
- 付款码保持清晰并居中显示。
- 点击遮罩、付款码区域、关闭按钮或按 `Esc` 均可关闭。
- 弹层使用对话框语义。
- 打开后焦点限制在弹层内。
- 关闭后焦点返回原支付按钮。
- 关闭按钮使用标准关闭图标并提供无障碍名称。
- 移动端图片尺寸受屏幕安全边距约束。

付款码资源缺失时：

- 弹层显示“付款码暂未配置”。
- 页面不抛出错误。
- 关闭行为保持可用。
- 后续只修改配置路径即可接入真实图片。

## 11. 响应式策略

### 11.1 桌面端

视口宽度大于等于 `761px` 时启用：

- 完整滚轮推拉。
- 平台卡片和支付方式滚筒。
- 下载安装左右侧移。
- 文件粒子、文件预览和鼠标光场。
- 悬停、点击锁定与键盘等价交互。

### 11.2 移动端

视口宽度小于等于 `760px` 时：

- 保留五章节顺序和缩放渐隐切换。
- 使用上下触屏手势和屏幕控制按钮切换章节。
- 降低章节缩放幅度、模糊强度和粒子数量。
- 下载安装信息面板使用下方抽屉。
- 支付方式支持点击和触屏拖动。
- 付款码弹层适配窄屏安全边距。

## 12. 减少动态效果

当 `prefers-reduced-motion: reduce` 生效时：

- 章节切换改为约 `180–240ms` 的交叉渐隐。
- 取消大幅缩放、透视、持续漂浮和箭头往复运动。
- 取消侧栏内容的长距离错峰移动，保留短淡入。
- 平台和支付滚筒使用直接状态切换或短淡入。
- 所有内容和操作保持完整可用。

## 13. 无障碍

- 所有点击目标至少为 `44×44px`。
- 可交互元素提供可见焦点样式。
- 箭头按钮、关闭按钮和卡片操作提供无障碍名称。
- 不仅依赖颜色表达平台状态。
- `coming-soon` 状态同时使用文字和禁用行为。
- 悬停行为必须支持键盘聚焦和点击锁定。
- 付款码弹层提供对话框语义、焦点约束和焦点恢复。
- 占位章节通过文字明确说明状态，不能表现为空白或加载失败。

## 14. 性能与生命周期

- 动画优先修改 transform 和 opacity。
- 连续滚轮期间避免读取会触发布局同步的尺寸。
- 共享视觉层只在需要它的章节激活。
- 非当前章节关闭指针事件。
- 页面失焦或标签页隐藏时暂停动画。
- 组件卸载时释放 GSAP 动画、事件监听、动画帧和 Canvas 资源。
- 图片预留稳定尺寸，避免布局偏移。
- 大型或非首屏模块可以按章节接近程度延迟加载。

## 15. 异常回退

GSAP、Canvas、图片或动画初始化失败时：

- 下载入口和文本内容不能消失。
- 当前章节以静态形式显示。
- 提供明确的上一章节和下一章节控制。
- Windows 真实下载链接保持可操作。
- macOS 保持“即将支持”状态。
- 付款码缺图使用“付款码暂未配置”回退。
- 不让异常导致整页黑屏或阻止章节导航。

## 16. 测试与验收

### 16.1 纯模型测试

- 全局进度边界和章节索引。
- 相邻章节局部进度。
- 正向与反向交接对称。
- 快速输入不能跨越多个章节。
- 最近章节吸附。
- 平台和支付方式循环索引。
- 局部滚筒输入优先级。
- 减少动态效果状态。

### 16.2 组件测试

- 五章节按确认顺序注册。
- 两个占位章节包含明确名称和状态。
- Windows 使用真实发行清单。
- macOS 可选中但不可下载。
- FAQ、安装须知和支付方式来自配置。
- 付款码图片缺失时显示稳定回退。
- 非当前章节禁用内部交互。

### 16.3 端到端测试

- 首页开场后进入章节导航。
- 鼠标滚轮和键盘逐章节切换。
- 反向输入返回前一章节。
- 下载安装左右面板的临时展开、锁定、切换和收回。
- 平台滚筒局部输入不会误切章节。
- Windows 下载链接正确。
- 捐款滚筒局部输入不会误切章节。
- 付款码弹层可以打开、关闭并恢复焦点。
- 触屏手势和窄屏抽屉可用。
- 减少动态效果路径可用。
- 初始化失败回退可用。

### 16.4 视觉检查

检查 `390px`、`768px`、`1440px` 和 `1920px` 视口：

- 模块推拉层级正确。
- 文字、按钮、卡片和弹层无重叠。
- 页面无横向滚动。
- 下载安装左右渐变与侧移符合设计。
- 捐款黄色光场和文件粒子正常显示。
- Canvas 通过非空像素检查。
- 付款码弹层不裁切。

## 17. 成功标准

- 五个章节均可按顺序到达，任何一次快速输入都不会跳过中间章节。
