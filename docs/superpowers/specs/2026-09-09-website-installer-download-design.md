# 官网 Windows 安装包下载接入规格

> 后续替代：本规格中“默认域作为正式按钮地址”的选择，已由[2026-09-14直接下载修正规格](2026-09-14-direct-installer-download-design.md)在该范围内替代，当前按钮使用 `cjmwebsite.cn`。下文默认域选择、旧安装包与费用数据保留为当日历史依据，不代表当前入口。

## 授权与目标

用户要求将已有安装包挂到当前正常的 `main` 官网，并在得知免费资源额度限制后明确选择：“继续使用当前免费环境，接受仅供少量测试的额度限制”。本规格记录该选择，复用既有发布清单和官方下载链，不新增下载服务。

目标是让官网 Windows 下载按钮取得实际安装包。仍按少量测试的未签名 Alpha 分发，不宣称正式生产上线或安装、卸载人工验收已通过。此前“未上传、未发布”的记录保留为历史事实，当前状态由本次独立验收记录说明。

## 实施方案与边界

1. 使用现有上海 CloudBase 静态托管的独立 `releases/0.1.0-alpha.1/` 目录，只上传最终 `.exe` 和对应 `.sha256` 文件。该目录在上传前为空。
2. Windows 按钮使用同一免费环境的默认 HTTPS 下载域：`https://ai-pet-scanner-dev-d0cpbc8094826-1391054083.tcloudbaseapp.com/releases/0.1.0-alpha.1/AI-Pet-0.1.0-alpha.1-windows-x64.exe`。该地址已通过完整下载与 SHA-256 校验；官网继续从 `cjmwebsite.cn` 提供页面。默认域仅用于本次已授权的少量测试，不使用匿名投稿私有 Bucket，不改对象权限、数据库或 API。
3. 使用修复后的现有生成器从真实文件生成发布清单，发布时间记录实际执行时刻；下载入口启用前先验证远端文件。
4. 保留现有组件、布局、动画、平台选择、macOS 未发布状态及下载计数行为。提示继续说明未签名和少量测试，标题改为“Alpha 测试版”，避免“邀请制”与公开链接冲突。
5. 官网六处直接依赖真实清单的测试同步为发布态，现有明确未发布夹具与失败计数测试继续保留。
6. 使用现有部署配置构建，先上传哈希资源，最后更新首页入口。只覆盖本次构建实际变更的文件，覆盖前保存原文件作为回退材料。

### 实测后的下载域选择

源站尾段校验通过，但公开下载后段失败；只读配置确认自定义 CDN 开启分片回源，源站却是忽略 Range 的 CloudBase 网关。为实现用户已授权的同环境安装包下载，允许尝试仅对上述安装包精确路径增加 `RangeOriginPull.RangeRules` 的 `Switch: off` 规则，保持全局 `Switch: on`。操作前保存原字段，并对其余配置生成指纹；操作后回读核对。普通 CDN 官方支持该规则，但 CloudBase 托管接口是否接受仍以实际返回为准。接口拒绝或下载复验仍失败时，不扩大到全局开关、ACL、网关、DNS 或付费资源；已生效的诊断规则恢复为原值。若需要刷新缓存，仅处理该安装包的单个 URL。[官方规则字段](https://cloud.tencent.com/document/product/228/30987)、[分片回源条件](https://intl.cloud.tencent.com/zh/document/product/228/7184)

上述规则请求实际被 `UnknownParameter` 拒绝，回读确认配置未变。最终采用当前环境自带下载域，普通完整 GET 返回全部 `2855778466` 字节且 SHA-256 一致；该地址返回附件下载响应，但实测忽略 Range，不承诺断点续传。此选择替代最初的官网同源安装包 URL；网站与文件仍属于用户批准的同一免费环境，不新增下载服务。

非目标：重打安装包、改变桌宠功能、修改网站其他业务、开通收费资源、购买套餐、启用按量付费、迁移托管、Git 写操作和批量删除。

## 失败处理、隐私与清理

- 上传或远端校验失败时不发布下载入口；传输命令限定十五分钟，超时记录并改用可判定的分片／进度方案。
- 复用 CLI 已有登录态；凭据不输出，不写入仓库或前端。生产构建保留现有公开配置，不混入 E2E 凭据。
- 远端文件不清空、不 prune，不更改共享资源、管理员、网关、DNS 或计费配置。
- 原整包读取路径被流式实现直接替换，不新增第二套生成器；原未发布清单由唯一新清单替换。

## 验证与验收

- TDD：先用大于 2 GiB 的真实文件夹具复现生成器失败，再验证流式实现的大小、完整 SHA-256 与读取错误传播。
- 官网：先更新真实发布态测试并观察失败，再生成清单，运行下载相关测试及 `pnpm.cmd verify:website`。
- 发布：核对远端对象大小，真实 HTTPS 响应与范围读取；完整下载后计算 SHA-256，与本地最终产物一致。完整验证下载本身也消耗当前套餐流量。
- 浏览器观察 Windows 下载入口、未签名提示和 macOS 未发布状态；不执行安装器。
- 最后运行 `git diff --check`，复核变更范围，记录实际结果、费用额度限制及未覆盖的安装验收。
